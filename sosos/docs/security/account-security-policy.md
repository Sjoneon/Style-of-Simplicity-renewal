# 계정 보안 정책 (초안)

## 적용 범위
- 사용자 계정의 비밀번호 변경
- 회원정보/배송지 수정 API

## 비밀번호 변경 정책
1. 현재 비밀번호 일치 검증이 선행되어야 한다.
2. 새 비밀번호는 기존 비밀번호와 동일하면 안 된다.
3. 길이 규칙: 최소 8자, 최대 72자(BCrypt 특성 반영)
4. 문자 규칙: 영문 1자 이상 + 숫자 1자 이상 포함
5. 저장 규칙: BCrypt 해시로 저장

## 세션 정책
1. 비밀번호 변경 성공 시 즉시 세션을 무효화한다.
2. 사용자에게 재로그인을 요구한다.

## 프로필/배송지 수정 정책
1. 로그인 사용자 본인 계정만 수정 가능
2. 이름/연락처/주소는 공백 값 금지
3. 연락처는 `010-XXXX-XXXX` 형식으로 정규화/검증

## 오류 응답 원칙
- 검증 실패: 400 Bad Request + 원인 메시지
- 비로그인: 401 Unauthorized
- 권한 불일치: 403 Forbidden
