# SOS 리뉴얼 로드맵

## 기준
- 목적: 프론트엔드와 백엔드를 분리하고 AWS 기준으로 실제 운영 가능한 구조를 만든다.
- 방식: 운영 기본선, API 경계, 핵심 화면, 배포 준비 순서로 진행한다.
- 기간: 1인 개발 기준 예상치이며 일정에 따라 조정한다.

## 1순위: 운영 기본선

### 1) 백엔드 운영 기본선 정리
- 내용: 비밀번호 해시, 환경변수 분리, dev/prod 설정 분리, Actuator 노출 최소화
- 예상: 3~5일
- 완료 기준: 민감정보 하드코딩 제거와 운영/개발 설정 분리 완료
- 상태: 완료 (2026-02-15)

### 2) API 경계 정리
- 내용: 기존 Thymeleaf 유지, `/api/v1/*` JSON API 추가
- 예상: 4~6일
- 완료 기준: 상품/사용자/주문 핵심 API가 통일된 응답 형식으로 동작
- 상태: 완료 (2026-02-19, 핵심 API 스모크 검증 완료)

### 3) 주문/재고 무결성 보강
- 내용: `@Transactional` 적용, 수량/상태 저장 일관성 확인
- 예상: 2~3일
- 완료 기준: 구매 시 재고/주문 데이터 불일치가 재현되지 않음
- 상태: 완료 (2026-02-22 14:37, 단위 테스트와 실기동 시나리오 검증 완료)

## 2순위: 핵심 기능 전환

### 4) 프론트엔드 프로젝트 시작
- 내용: `frontend/` 생성, React + Vite + MUI + Axios 구성
- 예상: 1~2일
- 완료 기준: 프론트 로컬 실행과 백엔드 API 1개 연동 확인
- 상태: 완료

### 5) 핵심 화면 마이그레이션
- 내용: 메인 목록, 상품 상세, 장바구니, 로그인/회원가입, 판매자 대시보드 전환
- 예상: 7~12일
- 완료 기준: 조회, 장바구니, 주문 흐름이 React 화면에서 동작
- 상태: 주요 흐름 완료, 판매자 대시보드 개선 진행

### 6) 이미지/파일 저장 전략 정리
- 내용: 로컬 절대경로 제거, dev(local)/prod(S3) 저장 전략 분리
- 예상: 2~4일
- 완료 기준: 로컬과 운영 환경에서 업로드 경로가 분리되어 동작
- 상태: 코드 경로 구현 완료, 실제 자격증명 검증 로그 확보 필요

## 3순위: 배포와 운영 점검

### 7) 배포 준비
- 내용: 백엔드 Dockerfile, 배포 설정, CORS/도메인, 환경변수 문서 정리
- 예상: 2~4일
- 완료 기준: 코드 수정 없이 환경변수만으로 실행 기준을 바꿀 수 있음
- 상태: 주요 문서와 Dockerfile 정리 완료

### 8) AWS 배포
- 내용: EC2(백엔드), RDS(MySQL), S3(프론트/이미지), CloudFront/WAF 운영
- 예상: 3~6일
- 완료 기준: 운영 도메인 접속, 로그인, API 호출, 이미지 업로드 확인
- 상태: 운영 경험 정리 완료, 일부 리허설 로그 보강 필요

### 9) 테스트/운영 점검
- 내용: 통합 시나리오, 로그 확인, 배포 후 회귀 체크
- 예상: 2~3일
- 완료 기준: 배포 후 기본 흐름을 같은 절차로 재검증 가능
- 상태: 검증 명령과 한글 깨짐 점검 스크립트 사용 중
