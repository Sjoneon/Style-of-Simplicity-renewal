# 1인 개발용 우선순위/ETA 운영 규칙

## 적용 범위
- 현재 프로젝트는 1인 개발 기준으로 운영한다.
- 데일리 기록에서 `블로커 담당자/요청 대상` 항목은 당분간 사용하지 않는다.

## 우선순위 규칙
- `P1`: 오늘 반드시 끝내야 하는 핵심 작업
- `P2`: 밀려도 전체 일정에 치명적 영향이 없는 작업
- 하루 시작 시 P1은 최대 1개, P2는 최대 1~2개만 둔다.

## ETA 규칙
- 형식: `YYYY-MM-DD HH:mm`
- 기준: "완료 기준(Definition of Done)을 충족하는 예상 시점"
- ETA가 밀리면 데일리 로그에 원인을 1줄로 남긴다.

## 기록 규칙
- 데일리 로그(`docs/daily/YYYY-MM-DD.md`)에 반드시 아래를 기록한다.
1. 오늘 우선순위(P1/P2)
2. 목표 완료 시점(ETA)
3. 우선순위/ETA 점검 결과

## 의사결정 1줄 규칙
- 형식: `무엇을 왜 선택했는지`를 한 줄로 기록
- 사용자가 질문에서 의사결정을 명시하지 않았고, 기록이 필요해 보이면 작업자가 먼저 확인한다.
