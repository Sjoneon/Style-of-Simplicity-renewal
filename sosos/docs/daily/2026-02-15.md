## 포트폴리오용 변화 요약 (기존 SOS vs 리뉴얼 SOS)
### 1) 성능/속도 변화
- 기존 SOS: 측정 기준 부재
- 리뉴얼 SOS: 운영 프로필에서 최소 노출/검증 기준 적용
- 변화 폭(%, ms, 초 등): 정량 측정 미수행
- 측정 방법/근거(도구, 링크, 캡처 경로): `actuator/health` 응답 확인, `actuator/env` 차단 확인

### 2) 기능 변화
- 기존 SOS: 평문 비밀번호 비교 가능성 존재
- 리뉴얼 SOS: BCrypt 해시 + 평문 자동 승격 + 비밀번호 검증 강화
- 사용자 관점 효과(무엇이 얼마나 좋아졌는지): 로그인 보안성 향상, 운영 설정 실수 위험 감소
- 근거(테스트 결과, 시나리오, 로그): 사용자 로그인 후 DB 해시 문자열(`$2a$...`) 확인

### 3) 기술/구조 변화
- 기존 SOS: 단일 설정 중심, DB/운영 값 혼재
- 리뉴얼 SOS: 프로파일 분리(dev/prod), 환경변수 기반, 스키마 타입 정합화
- 유지보수/확장성 관점 효과: 운영 배포 전 검증 안정성 증가, 환경별 설정 충돌 감소

### 4) 다음 비교 예정 항목
- API 경계 정리(`/api/v1/*`) 전/후 응답 표준화 비교
