# 2026-04-28 학습 메모 - 품목 검색형 요청 대응 보강

## 무엇
- 목표:
  - `반팔 추천`, `긴팔티 추천`, `반팔 셔츠 추천` 같은 검색형 요청을 스타일 대화 없이도 정확히 처리한다.
  - 상품명 중심 매칭을 강화해 사용자가 검색창처럼 챗봇을 써도 원하는 품목이 상위에 노출되게 한다.

## 왜
- 기존 설명/구현의 누락:
  - 누락 1: 짧은 품목 요청에서도 답변 끝 문구가 과도하게 스타일 질문으로 흐를 수 있었다.
  - 누락 2: `셔츠` 토큰이 `티셔츠`에 부분 일치해 `반팔 셔츠` 요청에서 `반팔 티셔츠`가 상위로 나올 수 있었다.
  - 누락 3: `티셔츠` 검색 시 기본적으로 반팔을 선호하는 일반 사용자 기대를 점수에 충분히 반영하지 못했다.

## 언제
- 사용자가 AI를 코디 상담뿐 아니라 상품 검색 대용으로 사용하는 구간에서 즉시 적용한다.
- 추천 결과가 품목명 의도와 다를 때(예: 셔츠 vs 티셔츠) 우선 점검한다.

## 어떻게
- 쉬운 용어 설명:
  - 검색형 요청: 스타일 설명 없이 제품 종류만 짧게 입력하는 요청
  - 품목 우선 점수: 요청한 품목명과 정확히 맞는 상품에 가점을 주는 규칙
- 구현 순서:
  1. 검색형 요청 단어 사전(`DIRECT_ITEM_TERMS`) 추가
  2. 품목 별칭 확장(`반팔티 -> 반팔 + 티셔츠`, `긴바지 -> 팬츠 + 바지`) 추가
  3. `셔츠`는 단어 단위 매칭으로 변경해 `티셔츠` 부분일치 오탐 차단
  4. 검색형 요청일 때 상품명/설명 매칭 점수를 높여 상품명 기반 정렬 강화
  5. 테스트로 `티셔츠`, `반팔 셔츠`, `반바지` 시나리오 고정
