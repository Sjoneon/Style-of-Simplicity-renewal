# AI 추천 2단계 구조 전환 학습 (2026-05-01)

## 무엇
- AI 추천을 `키워드 1차 필터 + LLM 프롬프트 2차 코디 설명` 구조로 전환한다.
- 스타일 동의어를 그룹화해서 1차 필터에서 의미 기반으로 후보를 좁힌다.

## 왜
- 사용자가 "힙한 상의"처럼 추상 표현을 써도, 상품 키워드가 "스트릿/트렌디"로 등록돼 있으면 같은 의미로 인식해야 추천 품질이 오른다.
- 상품 추천 목록과 코디 문장 생성을 분리하면, 추천 근거(규칙)와 문장 자연스러움(LLM)을 동시에 확보할 수 있다.

## 언제
- 스타일 표현이 다양해질수록(힙/시크/캐주얼/포멀/러블리 등) 운영자가 키워드를 관리하고 추천 품질을 유지할 때 필요하다.

## 어떻게
1. `AiStylistService`에 스타일 동의어 그룹 맵을 추가한다.
2. 사용자 입력에서 스타일 그룹을 파싱해 1차 필터(후보 축소)에 적용한다.
3. 추천 상품은 기존 규칙 점수로 뽑되, 스타일 그룹 매칭 상품을 우선한다.
4. 2차로 LLM 프롬프트를 구성해 코디 설명 문장을 생성한다.
5. 무료 API/쿨다운/키 미설정 상황에서는 로컬 설명으로 안전하게 fallback한다.
6. 단위 테스트로 힙함 계열 동의어(힙 -> 스트릿/트렌디) 인식이 동작하는지 검증한다.

## 쉬운 용어 설명
- 1차 필터: 조건에 맞는 상품 후보를 먼저 거르는 단계.
- 2차 설명: 고른 후보를 바탕으로 자연스러운 코디 문장을 만드는 단계.
- fallback: 외부 API가 안 될 때 내부 규칙으로 대신 응답하는 안전장치.

## 완료 기준 (DoD)
- "힙한 상의" 요청에서 스트릿/트렌디 키워드 상품이 1차 필터로 우선 추천된다.
- 코디 설명은 LLM 2차 경로(또는 fallback 경로)로 생성된다.
- 백엔드 테스트/컴파일/한글 깨짐 검사가 모두 통과한다.
