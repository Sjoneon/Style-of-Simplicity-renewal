# 판매자 대시보드 하위 메뉴 시각 분리 학습 (2026-06-16)

## 무엇
- 판매자 대시보드 좌측 메뉴에서 최상위 메뉴와 드롭다운 하위 메뉴의 선택 색을 다르게 만든다.
- 하위 메뉴는 밝은 배경, 왼쪽 기준선, 안쪽 여백으로 부모 메뉴와 분리되어 보이게 한다.

## 왜
- 부모 메뉴와 하위 메뉴가 모두 검은색으로 선택되면 두 항목이 붙어 보여 현재 위치를 한눈에 구분하기 어렵다.
- 하위 메뉴는 부모 메뉴의 내부 항목이므로 같은 강조 색보다 한 단계 약한 강조가 더 자연스럽다.

## 언제
- 드롭다운 메뉴에서 부모와 자식 항목이 동시에 강조되어 시각적으로 뭉쳐 보일 때 적용한다.

## 어떻게
1. 최상위 메뉴의 선택 스타일은 검은 배경으로 유지한다.
2. 하위 메뉴의 선택 스타일은 밝은 회색 배경과 검은 글자로 따로 정의한다.
3. 하위 메뉴 묶음에 왼쪽 경계선을 추가해 들여쓰기 구조가 보이게 한다.
4. 프론트 린트/빌드와 한글 깨짐 검사를 실행한다.

## 쉬운 용어
- 부모 메뉴: `홈 관리`, `Q&A`처럼 하위 메뉴를 여는 큰 메뉴다.
- 하위 메뉴: `메인 배너 관리`, `홈 탐색 관리`처럼 부모 메뉴 안에 들어 있는 메뉴다.
- 선택 스타일: 현재 선택된 메뉴에 적용되는 배경색, 글자색, 테두리 같은 화면 표현이다.
