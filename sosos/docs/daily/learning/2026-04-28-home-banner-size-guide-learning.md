# 2026-04-28 학습 메모 - 홈 배너 이미지 규격 가이드

## 무엇
- 목표:
  - 판매자 배너 등록 화면에서 홈 배너 권장 이미지 픽셀 규격을 바로 안내한다.
  - 배너가 잘리는 이유(`cover` 방식)와 안전한 제작 기준(비율/중앙 배치)을 함께 설명한다.

## 왜
- 기존 누락:
  - 배너 등록 폼에 이미지 규격 정보가 없어 판매자가 임의 크기로 업로드했다.
  - 결과적으로 홈 화면에서 이미지가 예기치 않게 잘려 보이는 사례가 발생했다.

## 언제
- 판매자가 메인 광고 배너를 새로 등록하거나 교체할 때 적용한다.

## 어떻게
- 쉬운 용어 설명:
  - 비율(Aspect Ratio): 가로:세로 비율. 홈 배너는 넓은 가로형(약 4:1)에 가깝다.
  - 안전 영역(Safe Area): 기기별 잘림이 있어도 핵심 텍스트/피사체가 남는 중앙 구간
- 구현 순서:
  1. 판매자 대시보드 `메인 광고 배너 관리` 폼에 권장 규격 안내 문구 추가
  2. 권장 규격을 `최소 1200x300`, `권장 2400x600`(4:1)로 명시
  3. 모바일/가변 화면 잘림을 고려해 핵심 요소 중앙 배치 가이드를 함께 표시
  4. 프론트 린트로 정적 검증 수행
