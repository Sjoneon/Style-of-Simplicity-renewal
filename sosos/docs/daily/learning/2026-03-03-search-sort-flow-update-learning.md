# 검색 플로우 조정: 팝업에서는 검색만, 정렬은 검색 후 결과 영역에서

## 무엇
- 검색 버튼으로 여는 팝업에서는 `검색어` 중심으로만 입력받고, `정렬` 선택은 제거합니다.
- 정렬은 검색 적용 후 결과 영역에서 변경하도록 이동합니다.
- 검색 기록/인기 검색어 저장 로직이 유지되는지 확인합니다.

## 왜
- 검색 시작 단계에서 옵션이 많으면 초보 사용자가 복잡하게 느낍니다.
- 검색 결과를 본 뒤 정렬을 바꾸는 흐름이 일반 쇼핑 UX와 더 맞습니다.
- 기록/인기 검색어가 유지되어야 재검색이 쉬워지고 상품 노출도 늘어납니다.

## 언제
- 요청 반영 일시: 2026-03-03
- 적용 범위: 홈 메인 검색 UI

## 어떻게
- `frontend/src/pages/HomePage.jsx`
  - 검색 팝업에서 `정렬` 입력 UI와 draft 상태를 제거합니다.
  - 검색 적용 함수는 검색어/재고 필터만 반영하도록 단순화합니다.
  - 검색 후 노출되는 결과 정보 박스에 `정렬` 선택 UI를 배치합니다.
- 저장 로직 검증
  - 최근 검색어: `sos-search-history-user-{id}` 키에 사용자별 저장
  - 인기 검색어: `sos-popular-search-terms-v1` 키에 누적 저장

## 쉬운 용어
- 팝업: 검색 버튼 클릭 시 열리는 작은 창
- 결과 영역: 검색 후 상품 리스트 위에 보이는 정보 박스
- 로컬스토리지: 브라우저 안에 저장되는 간단한 데이터 저장소

## 완료 기준(Definition of Done)
- 검색 팝업에서 정렬 항목이 보이지 않는다.
- 검색 후 결과 영역에서 정렬을 바꿀 수 있다.
- 최근 검색어/인기 검색어가 기존처럼 계속 표시된다.
