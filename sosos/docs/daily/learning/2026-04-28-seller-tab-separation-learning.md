# 2026-04-28 학습 메모 - 판매자 대시보드 탭 분리 정리

## 무엇
- 목표:
  - `메인 광고 배너 관리`, `등록 배너 목록`, `홈 탐색 탭 관리`를 `상품 관리` 탭에서 분리한다.
  - 판매자 대시보드에 별도 `홈 관리` 탭을 만들어 홈 운영 항목을 모은다.
  - 판매자 로그인 화면의 `슈퍼관리자` 문구를 `판매자` 기준으로 바꾼다.

## 왜
- 기존 설명/구현의 누락:
  - 누락 1: 상품 관리와 홈 운영 항목이 섞여 있어 카테고리 의미가 맞지 않았다.
  - 누락 2: 판매자 로그인 화면에 `슈퍼관리자` 문구가 남아 사용자 역할 인식이 혼동됐다.

## 언제
- 대시보드 기능이 늘어나 탭 의미를 역할별로 분리해야 할 때 적용한다.

## 어떻게
- 쉬운 용어 설명:
  - 홈 관리: 배너/홈 탭 같은 메인 노출 구성 관리 영역
  - 상품 관리: 실제 판매 상품 등록/수정/삭제 관리 영역
- 구현 순서:
  1. 탭 바에 `홈 관리` 탭 추가
  2. 배너/탐색탭 블록을 `home` 탭 조건으로 이동
  3. `products` 탭에는 등록 상품 목록 + 상품 등록/수정 흐름만 유지
  4. `AdminLoginPage`의 `슈퍼관리자` 문구를 `판매자` 기준으로 교체
  5. 프론트 린트 실행
