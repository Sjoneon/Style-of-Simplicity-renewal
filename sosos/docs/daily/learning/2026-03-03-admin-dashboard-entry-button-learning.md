# 슈퍼관리자 전용 대시보드 진입 버튼 추가

## 무엇
- 헤더에 `슈퍼관리자 대시보드` 이동 버튼을 추가합니다.
- 이 버튼은 `관리자(seller) 로그인 상태`에서만 보이게 합니다.

## 왜
- 현재는 메인으로 이동 후 대시보드 재진입 경로가 부족해 뒤로가기에 의존하게 됩니다.
- 관리자 기능 진입점은 필요하지만, 비로그인/일반 사용자에게 노출되면 안 됩니다.

## 언제
- 요청 반영 일시: 2026-03-03
- 적용 위치: 상단 헤더 네비게이션

## 어떻게
- `frontend/src/components/AppLayout.jsx`
  - 현재 로그인 사용자 타입을 확인해 `user.userType === 'seller'`일 때만 버튼 렌더링
  - 버튼 클릭 시 `/admin/dashboard` 이동
- 기존 관리자 라우트 보호(`RequireAdmin`)는 유지하여 URL 직접 접근도 차단

## 쉬운 용어
- 렌더링: 화면에 실제로 보이게 그리는 것
- 조건부 렌더링: 특정 조건일 때만 요소를 보여주는 방식
- 보호 라우트: 권한 없으면 접근을 막는 URL 규칙

## 완료 기준(Definition of Done)
- 관리자 로그인 시에만 헤더에 `슈퍼관리자 대시보드` 버튼이 보인다.
- 비로그인/일반 사용자 로그인 시에는 버튼이 보이지 않는다.
- 버튼으로 `/admin/dashboard`로 즉시 이동 가능하다.
