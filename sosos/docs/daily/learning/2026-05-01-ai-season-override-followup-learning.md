# 2026-05-01 AI 계절 전환 후속 패치 학습

## 무엇
- 증상: 사용자가 대화 중 계절을 `여름 -> 겨울`로 바꿨는데, 추천 결과에 기존 여름 상품이 계속 섞여 나오는 문제를 수정한다.
- 대상 파일:
  - `sosos/src/main/java/com/prosos/sosos/service/AiStylistService.java`
  - `sosos/src/test/java/com/prosos/sosos/service/AiStylistServiceTest.java`
- 완료 기준(DoD):
  - 계절 수정 후속 질문에서 최신 계절이 우선 반영되고, 반대 계절 대표 상품이 상위 추천에서 제외된다.

## 왜
- 현재 로직은 계절 “가산점”은 있지만, 반대 계절 “감점/제외”가 약해서 이전 계절 상품이 카테고리 가산점으로 다시 올라올 수 있다.
- 사용자는 계절을 바꾸면 즉시 추천 맥락이 바뀌기를 기대하므로, 최신 의도 우선이 신뢰도에 핵심이다.

## 언제
- 멀티턴 대화에서 사용자가 `아 미안, 계절 겨울`처럼 의도를 정정하는 상황.
- 여름/겨울처럼 상충이 큰 계절 전환 상황에서 우선 적용.

## 어떻게
1. 최신 계절 신호를 추출한다(이미 도입된 `resolveSeasonSignalMessage` 활용).
2. `scoreSeasonPreference`에 계절 충돌 감점을 추가한다.
3. 감점 결과 `score <= 0`이면 후보에서 탈락하도록 기존 흐름을 유지한다.
4. 회귀 테스트(`AiStylistServiceTest`)로 여름->겨울 전환 시나리오를 검증한다.
5. 검증 후 일일 로그에 결과를 기록한다.
