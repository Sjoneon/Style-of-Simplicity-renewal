# 상품 키워드 한글화 및 운영 데이터 동기화 학습 (2026-05-02)

## 무엇
- 현재 등록된 상품 키워드가 영어로 저장된 문제를 한글 키워드로 교체한다.
- 상품 대표 이미지(카테고리별 샘플)를 확인해 카테고리/스타일에 맞는 키워드로 보정한다.
- 재시드 스크립트의 기본 키워드도 한글로 바꿔 재발을 막는다.
- 대상 파일:
  - `scripts/reseed-products-from-uploads.ps1`
  - `sosos/docs/daily/learning/README.md`

## 왜
- 판매자/운영자 입장에서 키워드가 영어면 관리가 어렵고, AI 추천 규칙(한국어 질의 중심)과도 어긋난다.
- 재시드 스크립트가 영어 키워드를 다시 주입하면 같은 문제가 반복된다.

## 언제
- 상품 대량 등록 직후 키워드 품질을 맞추고, AI 추천 정확도를 높여야 할 때 즉시 필요하다.
- 운영 중 키워드 기준을 한국어 중심으로 통일하려는 시점에 필요하다.

## 어떻게
1. DB에서 현재 상품명/카테고리/키워드 현황을 조회한다.
2. 카테고리별 대표 이미지를 실제로 확인해 키워드 초안을 확정한다.
3. 상품명 기준 한글 키워드 매핑으로 DB를 일괄 업데이트한다.
4. 재시드 스크립트의 기본 키워드 문자열도 한글로 교체한다.
5. 깨진 한글 검사 스크립트를 실행해 인코딩 이상 여부를 확인한다.

## 쉬운 용어 설명
- 재시드: 기존 상품 데이터를 지우고, 정해진 목록으로 다시 채워 넣는 작업.
- 키워드 매핑: 상품명마다 들어갈 키워드를 미리 정한 표.
- 일괄 업데이트: 상품 하나씩 수동 수정하지 않고 한 번에 반영하는 방식.

## 완료 기준 (DoD)
- 등록된 57개 상품의 키워드가 영어 대신 한글 키워드로 교체된다.
- 재시드 스크립트 기본 키워드도 한글로 저장되어 재실행 시 영어가 재주입되지 않는다.
- 한글 깨짐 검사에서 신규 변경 파일에 이상이 없다.
