# 일반 로그인과 관리자 로그인 완전 분리

## 무엇
- 일반 로그인/회원가입 화면(`/auth`)에서 판매자(사업자번호) 로그인 안내를 제거합니다.
- `/auth`는 사용자 이메일 로그인 전용으로 고정합니다.
- 관리자 로그인은 `/admin/login`으로만 안내합니다.

## 왜
- 현재 문구가 남아 있으면 사용자가 일반 로그인에서 관리자 계정을 시도하게 되어 UX가 혼동됩니다.
- 로그인 진입점이 분리되어야 권한 모델이 명확해집니다.

## 언제
- 요청 반영 일시: 2026-03-03
- 적용 화면: 일반 로그인/회원가입 화면

## 어떻게
- `frontend/src/pages/AuthPage.jsx`
  - 로그인 설명 문구를 사용자 이메일 전용으로 변경
  - 로그인 입력 placeholder를 사용자 이메일 전용으로 변경
  - 로그인 폼 하단에 `슈퍼관리자 로그인` 이동 버튼 추가(`/admin/login`)
  - 일반 로그인에서 관리자 계정(`seller`)으로 인증되면 세션 종료 후 관리자 로그인 페이지로 안내

## 쉬운 용어
- 진입점: 기능을 시작하는 화면 주소
- 세션 종료: 로그인 상태를 지우는 처리
- 분리: 같은 기능처럼 보이지 않게 역할별로 나눔

## 완료 기준(Definition of Done)
- `/auth` 화면에서 사업자 로그인 안내가 보이지 않는다.
- 관리자 로그인은 `/admin/login` 안내로만 이동한다.
