# 2026-03-19 마이페이지 5개 섹션 확장 학습

## 무엇
- 마이페이지를 실제 쇼핑몰 구조에 맞춰 5개 섹션으로 확장한다.
- 순서: 주문 관리 -> 혜택 관리 -> 찜/최근 본 -> 리뷰/문의 -> 계정 관리

### 오늘 작업 대상 파일 경로
- `frontend/src/pages/MyPagePage.jsx`

### 완료 기준(DoD)
- 마이페이지에 5개 섹션이 순서대로 표시되고, 현재 API가 있는 주문/문의 데이터는 실데이터로 조회된다.
- `계정 유형` 라인은 제거되고, 계정 관리 섹션에는 이름/이메일(또는 사업자번호)만 표시된다.

## 왜
- 기존 MVP는 주문 중심이라 마이페이지 전체 구조(혜택/활동/계정관리)를 한눈에 보기 어렵다.
- 사용자 요구사항에 맞춰 쇼핑몰 표준 정보 구조로 정리할 필요가 있다.

## 언제
- 고객센터 MVP와 기본 마이페이지 MVP 완료 후, 마이페이지 UX를 확장하는 단계에서 적용한다.

## 어떻게
1. 주문/문의 API를 동시에 호출하는 데이터 로더 구성
2. 5개 섹션을 순서 고정으로 배치
3. API 없는 항목(쿠폰/적립금/찜/최근본/리뷰)은 `준비중` 카드로 우선 구성
4. 계정 관리에서 `계정 유형` 문구 제거
5. 린트/빌드로 회귀 확인

## 쉬운 용어 설명
- 섹션: 한 페이지 안에서 목적별로 나눈 정보 묶음
- 실데이터 연동: 화면에 임시 문구가 아니라 실제 API 결과를 표시하는 것
