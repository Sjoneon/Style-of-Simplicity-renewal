# 2026-04-30 AI 추천 조합 일반화 학습 메모

## 무엇
- AI 스타일 추천의 조합 인식을 `상하의` 같은 특정 표현 중심에서, 다양한 카테고리 조합을 공통 처리하는 구조로 바꾼다.
- 작업 파일:
  - `sosos/src/main/java/com/prosos/sosos/service/AiStylistService.java`
  - `sosos/src/test/java/com/prosos/sosos/service/AiStylistServiceTest.java`

## 왜
- 사용자는 `상의+하의`, `아우터/신발`, `반팔/반바지`, `신발 빼고 상하의`처럼 조합과 제외 조건을 섞어서 입력한다.
- 특정 문구를 하드코딩하면 케이스가 늘어날수록 유지보수가 어려워지고 누락이 잦다.

## 언제
- 카테고리 조합 요청에서 일부 품목만 추천되거나, 제외 의도가 반영되지 않을 때 적용한다.

## 어떻게
1. 카테고리 의도 파싱을 공통 함수로 통합한다.
- `includeCategory(...)`로 `요청 여부 + 제외 문구`를 함께 판정한다.
2. 제외 표현을 반영한다.
- `빼고/제외/말고/없이` 패턴을 감지해 해당 카테고리를 의도에서 제거한다.
3. 후보 재정렬을 범용화한다.
- 요청 카테고리가 여러 개면 각 카테고리 상위 후보를 먼저 배치한다.
- 이후 원래 점수 순 후보를 이어붙여 다양성과 점수 품질을 같이 유지한다.
4. 회귀 테스트를 추가한다.
- 혼합 조합(예: 아우터+신발) 보장
- 제외 문구(예: 신발은 빼고) 반영

## 완료 기준(Definition of Done)
- 다양한 조합 요청에서 의도한 카테고리들이 함께 추천되고, 제외한 카테고리는 추천 목록에서 빠진다.
