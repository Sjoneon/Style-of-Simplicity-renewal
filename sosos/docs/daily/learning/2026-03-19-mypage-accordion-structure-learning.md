# 2026-03-19 MyPage 아코디언형 정보 구조 학습

## 무엇
마이페이지에서 정보가 한 화면에 많이 노출되어 복잡해 보이는 문제를 해결하기 위해, 섹션을 아코디언(접기/펼치기) 구조로 바꾼다.

변경 대상
- `frontend/src/pages/MyPagePage.jsx`

완료 기준(DoD)
- 각 섹션(주문/혜택/찜·최근본/리뷰·문의/계정관리)이 기본적으로 접힌 상태로 보인다.
- 사용자가 섹션 제목을 클릭하면 해당 섹션의 상세 기능이 펼쳐진다.
- 기존 기능(주문 조회, 문의 요약, 계정 수정 폼)은 삭제 없이 그대로 동작한다.

## 왜
지금 화면은 모든 카드와 입력 영역이 동시에 보여서, 필요한 기능을 찾기 전에 시각 피로가 먼저 온다.

쇼핑몰 마이페이지는 보통 아래 흐름이 더 직관적이다.
- 1차: 항목명 + 요약치만 빠르게 스캔
- 2차: 필요한 항목만 열어서 상세 작업

즉, "정보 접근은 유지"하면서 "초기 노출량"만 줄이는 것이 목적이다.

## 언제
- 마이페이지 MVP 기능이 이미 붙어 있는 상태에서
- 사용자가 "클릭해야 세부 내용을 보는 구조"로 정리를 요청한 시점

## 어떻게
1. 5개 섹션을 `Accordion` UI로 전환한다.
2. 기본 상태는 모두 접힘으로 두고, 클릭한 항목만 열리게 한다.
3. 섹션 헤더에는 핵심 요약(건수/상태)을 남겨 탐색 속도를 유지한다.
4. 상세 콘텐츠에는 기존 폼/리스트/버튼 로직을 그대로 재사용한다.
5. 린트/빌드로 화면 회귀 검증을 수행한다.
