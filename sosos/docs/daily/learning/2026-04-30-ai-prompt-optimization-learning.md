# 2026-04-30 AI 스타일 추천 프롬프트 단순화 학습 메모

## 무엇
- AI 스타일 추천에서 "여름 상하의 추천"처럼 의도(상의+하의)를 분명히 말해도 하의만 추천하거나, 지원 불가 문구로 빠지는 문제를 개선한다.
- 이번 작업 대상 파일:
  - `sosos/src/main/java/com/prosos/sosos/service/AiStylistService.java`
  - `sosos/src/test/java/com/prosos/sosos/service/AiStylistServiceTest.java`

## 왜
- 현재 프롬프트/가드레일이 길고 분기가 많아, "코디 추천" 문구가 없으면 과하게 차단되거나 카테고리 해석이 흔들린다.
- 사용자는 검색처럼 "반팔 추천", "여름 상하의" 같은 짧은 질의를 많이 쓰므로, 단순 상품 질의도 의류 추천으로 정상 처리해야 한다.

## 언제
- AI 추천 기능의 실사용 피드백에서 "의도와 다른 카테고리 추천" 또는 "지원 불가 오탐"이 보이면 즉시 반영한다.

## 어떻게
1. 프롬프트를 짧게 줄이고 우선순위를 명시한다.
- 1순위: 사용자 카테고리/시즌/예산 의도
- 2순위: 의류 요청 시 상의/하의 균형 추천
- 3순위: 부족한 정보만 짧게 재질문
2. "코디" 키워드 의존을 줄이고 의류 단어(반팔/긴팔/셔츠/반바지/슬랙스/청바지/상하의)를 추천 의도로 허용한다.
3. "상하의" 요청이면 상의 1개 + 하의 1개 이상이 나오도록 후보 후처리 규칙을 추가한다.
4. 회귀 테스트를 추가/보강해 짧은 질의가 차단되지 않는지 검증한다.

## 완료 기준(Definition of Done)
- "여름 상하의 추천" 질의에서 지원 불가 문구 대신 상의/하의 조합 추천이 안정적으로 반환된다.
