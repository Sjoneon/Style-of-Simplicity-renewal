# 2026-03-07 문의 상품명 표기 전환 + 문의 데이터 초기화 학습

## 무엇
- 고객센터에서 문의 연결/목록 표기를 `상품 ID` 중심에서 `상품명` 중심으로 바꾼다.
- 기존 문의 데이터를 모두 삭제하고 초기 상태로 리셋한다.

### 오늘 작업 대상 파일 경로
- `frontend/src/pages/ProductDetailPage.jsx`
- `frontend/src/pages/CustomerCenterPage.jsx`
- `sosos/docs/daily/2026-03-07.md`
- `sosos/docs/work-summary.md`

### 완료 기준(DoD)
- 고객센터 안내/목록에서 상품명이 표시되고, 문의 데이터 건수가 0으로 초기화되면 완료.

## 왜
- 사용자 입장에서 숫자 ID보다 상품명이 더 직관적이다.
- 테스트를 처음부터 다시 하려면 기존 문의 이력 정리가 필요하다.

## 언제
- 고객센터 사용 테스트 중 요구사항 변경(상품명 표시)과 데이터 초기화 요청이 들어와 즉시 반영한다.

## 어떻게
1. 상품 상세 -> 고객센터 이동 시 `productId`와 `productName`을 함께 전달
2. 고객센터에서 상품 카탈로그를 읽어 `productId -> 상품명` 매핑
3. 안내 문구/문의 목록 표시를 `상품명` 기준으로 렌더링
4. DB에서 `inquiries` 전체 삭제 + `AUTO_INCREMENT` 초기화
5. 프론트/백엔드 검증 실행

## 쉬운 용어 설명
- 매핑: 숫자 ID를 사람이 읽기 쉬운 이름으로 바꿔 보여주는 연결표
- 초기화: 기존 테스트 데이터를 지우고 새로 시작 가능한 상태로 되돌리는 것
