# 2026-03-03 메인 목록 UX 보강 학습 노트

## 무엇
- 기존 메인 목록 UI를 베이스로 UX를 보강한다.
- 적용 범위는 `1안(Baseline+)`과 `비로그인 담기 시 부드러운 로그인 유도`다.
- 주요 변경 요소:
  - 상단 검색/정렬/필터 영역 강화
  - 좌측 카테고리 스티키 내비게이션
  - 상품 카드 정보 우선순위 정리
  - 비로그인 장바구니 담기 시 즉시 이동 대신 안내 다이얼로그 제공

## 왜
- 사용자가 상품을 더 빨리 찾고(검색/정렬/필터), 더 적은 클릭으로 행동(담기/상세 확인)하도록 만들기 위해서다.
- 로그인 강제 이동은 흐름을 끊기 쉬워 이탈을 만들 수 있으므로, 안내 후 사용자가 선택하도록 바꾸는 게 UX에 유리하다.

## 언제
- 로드맵 5번(핵심 화면 마이그레이션) 품질 보강 단계에서 즉시 적용한다.
- 완료 기준(DoD):
  - 메인 목록에 검색/정렬/재고 필터/카테고리 스티키 UI가 동작
  - 비로그인 상태에서 `담기`를 누르면 안내 다이얼로그가 뜨고, 사용자가 로그인 이동 여부를 선택 가능
  - 프론트 `lint`, `build` 통과

## 어떻게
1. 메인 화면 레이아웃을 재구성한다.
- 좌측: 카테고리 목록(스티키)
- 우측: 상단 컨트롤(검색/정렬/필터) + 상품 그리드

2. 상품 목록 표시 로직을 분리한다.
- 필터(검색어/카테고리/재고) 적용
- 정렬(최신순/가격 오름차순/가격 내림차순/이름순) 적용

3. 로그인 유도 방식을 부드럽게 바꾼다.
- 비로그인 상태에서 담기/바로주문 시 로그인 페이지로 즉시 이동하지 않는다.
- 먼저 안내 다이얼로그를 띄우고 `계속 둘러보기` / `로그인하기`를 선택하도록 한다.

4. 공통 컴포넌트를 재사용한다.
- 로그인 유도 다이얼로그를 공통 컴포넌트로 만들어 홈/상세에서 같이 사용한다.

## 쉬운 용어 설명
- 스티키(sticky): 스크롤해도 지정 위치에 붙어서 계속 보이는 UI.
- 정렬(sort): 같은 데이터 목록을 특정 기준으로 순서를 다시 배치하는 것.
- 필터(filter): 조건에 맞는 데이터만 남기는 것.
- 모달/다이얼로그: 화면 위에 잠깐 뜨는 안내 창.
