# 2026-04-28 학습 메모 - AI 추천 로직 한글 근거 주석 보강

## 무엇
- 목표:
  - AI 추천 안전/검색 보강 로직에 “왜 만들었는지”를 한글 주석으로 남긴다.
  - 사후 유지보수 시 코드를 처음 보는 사람도 의도를 빠르게 이해할 수 있게 한다.

## 왜
- 기존 설명/구현의 누락:
  - 누락 1: 로직은 동작하지만, 외부쇼핑몰 차단/검색형 가중치 같은 정책성 결정의 배경이 코드에 남지 않았다.
  - 누락 2: 시간이 지난 뒤 사후처리(수정/삭제/정책변경) 시 왜 해당 규칙이 들어갔는지 추적이 어렵다.

## 언제
- 정책성 분기(차단/가중치/오탐 방지)처럼 “왜 이렇게 했는지”가 중요한 코드를 수정할 때 즉시 적용한다.

## 어떻게
- 쉬운 용어 설명:
  - 근거 주석: 기능 설명이 아니라, 해당 규칙을 넣은 이유를 짧게 남기는 주석
  - 사후처리: 운영 후 버그 수정, 정책 완화/강화, 리팩터링 같은 후속 작업
- 구현 순서:
  1. 안전 차단 규칙 블록에 정책 이유 주석 추가
  2. 검색형 품목 매칭/가중치 블록에 사용자 행동 기반 이유 주석 추가
  3. 오탐 방지(`셔츠` vs `티셔츠`) 블록에 회귀 방지 이유 주석 추가
  4. 한글 깨짐 문자(Replacement Character) 검사 실행
