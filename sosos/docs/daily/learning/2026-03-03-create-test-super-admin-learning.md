# 테스트용 슈퍼관리자 계정 생성

## 무엇
- 로컬 DB `sos_db.sellers`에 테스트용 슈퍼관리자 1개 계정을 생성합니다.

## 왜
- 현재 `sellers` 테이블이 비어 있어 `/admin/login` 검증이 불가능합니다.
- 소규모 테스트 목적이므로 쉬운 자격증명으로 빠르게 확인합니다.

## 언제
- 요청 반영 일시: 2026-03-03

## 어떻게
- `business_number` 형식(`000-00-00000`)을 만족하는 값으로 upsert합니다.
- 비밀번호는 테스트 편의를 위해 평문으로 넣고, 첫 로그인 성공 시 서비스 로직이 해시로 승격합니다.

## 쉬운 용어
- upsert: 있으면 수정, 없으면 생성
- 해시 승격: 평문 비밀번호를 로그인 시 암호화 저장으로 바꾸는 처리

## 완료 기준(Definition of Done)
- `/admin/login`에서 새 계정으로 로그인 시도 가능하다.
