# 2026-04-28 학습 메모 - 홈 배너 새로고침 깜빡임 방지

## 무엇
- 목표:
  - 메인 홈에서 새로고침(F5) 시 배너가 오기 전에 `현재 리뉴얼 중입니다...` 문구가 잠깐 노출되는 깜빡임을 제거한다.
  - 배너 API 로딩 중 상태와 "실제로 배너가 없음" 상태를 분리한다.

## 왜
- 기존 누락:
  - 배너 로딩 완료 전에도 `currentBanner`가 비어 있으면 즉시 fallback 문구를 렌더했다.
  - 그래서 정상 배너가 곧 도착하는 경우에도 fallback 문구가 잠깐 보였다.

## 언제
- 배너 데이터를 비동기로 불러오는 모든 초기 진입/새로고침 상황에서 적용한다.

## 어떻게
- 쉬운 용어 설명:
  - 로딩 상태: 서버 응답을 기다리는 중인 상태
  - 빈 상태: 서버 응답까지 끝났는데 보여줄 데이터가 없는 상태
- 구현 순서:
  1. `HomePage`에 배너 전용 로딩 상태(`bannerLoading`) 추가
  2. 배너 API 요청 시작 시 `true`, 완료 시 `false`로 전환
  3. 배너 영역 렌더를 `로딩 -> 배너 표시 -> 빈 상태` 순서로 분기
  4. 프론트 린트 실행으로 정적 검증
