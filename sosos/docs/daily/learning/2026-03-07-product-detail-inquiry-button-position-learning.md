# 2026-03-07 상품 상세 문의 버튼 위치/라벨 수정 학습

## 무엇
- 상품 상세 페이지에서 문의 버튼 위치를 하단에서 상단 영역으로 옮긴다.
- 버튼 문구를 `이 상품 문의하기`에서 `상품 문의`로 바꾼다.

### 오늘 작업 대상 파일 경로
- `frontend/src/pages/ProductDetailPage.jsx`
- `sosos/docs/daily/2026-03-07.md`
- `sosos/docs/work-summary.md`

### 완료 기준(DoD)
- 상품 상세 화면에서 문의 버튼이 상단 우측에 보이고, 버튼 라벨이 `상품 문의`로 표시되면 완료.

## 왜
- 기존 위치는 구매 버튼 아래에 있어 시선 이동이 길고, 사용자가 빠르게 문의 진입점을 찾기 어렵다.
- 버튼 문구를 짧게 정리하면 화면 밀도가 높은 상품 상세에서 가독성이 좋아진다.

## 언제
- 사용자 피드백으로 UI 위치/문구 개선 요청이 들어왔으므로 즉시 반영한다.

## 어떻게
1. 상품명 영역을 가로 레이아웃으로 바꿔 우측에 문의 버튼 배치
2. 기존 하단 문의 버튼 제거
3. 버튼 라벨을 `상품 문의`로 변경
4. 프론트 린트/빌드로 확인

## 쉬운 용어 설명
- 상단 우측 배치: 사용자 시선이 먼저 가는 제목 근처에 액션을 두는 방식
