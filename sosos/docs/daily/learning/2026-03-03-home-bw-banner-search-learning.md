# 2026-03-03 홈 화면 재구성 학습 노트 (블랙/화이트 + 배너 + 검색 아이콘)

## 무엇
- 홈 화면 상단 UX를 블랙/화이트 모던 스타일로 재구성한다.
- 좌측 카테고리 방식은 제거하고, 상단 탭/카테고리 선택 방식으로 통일한다.
- 정적 소개 문구 대신 판매자 업로드 상품 이미지를 활용한 회전 배너를 추가한다.
- 검색 영역은 큰 고정 박스 대신 돋보기 클릭형(검색 다이얼로그)으로 변경한다.
- 로그인 사용자 기준 검색 히스토리를 저장하고, 인기 검색어를 노출한다.

## 왜
- 현재 상단 영역이 크고 정보 밀도가 낮아 실제 상품 탐색보다 UI가 먼저 보인다.
- 사용자는 “탐색 > 검색 > 상품 클릭” 흐름을 빠르게 원하므로 검색 진입을 간결하게 만들어야 한다.
- 배너를 통해 판매자가 올린 상품을 추천 노출하면 초보 사용자도 진입 후 바로 클릭할 수 있다.

## 언제
- 로드맵 5번(핵심 화면 마이그레이션) 상세 UX 보강 단계에서 즉시 반영한다.
- 완료 기준(DoD):
  - 상단 메뉴에서 `메인 목록` 제거, `고객센터/마이페이지/알림/로그인·로그아웃` 노출
  - 회전 배너 클릭 시 해당 상품 상세 이동
  - 돋보기 클릭 시 검색 다이얼로그 열림
  - 검색 히스토리/인기 검색어 노출 및 검색 반영
  - 탐색 탭/카테고리 탭이 위아래로 붙어 보이도록 배치

## 어떻게
1. 네비게이션 구조를 개편한다.
- 사용자 이름 칩 제거
- 메뉴 항목을 요청 구조로 변경

2. 홈 상단 배너를 구성한다.
- 상품 목록 중 이미지가 있는 항목으로 슬라이드 목록 생성
- 일정 주기로 자동 전환
- 배너 클릭 시 `/products/:id` 이동

3. 검색을 아이콘 진입형으로 전환한다.
- 돋보기 버튼 클릭 -> 검색 다이얼로그 오픈
- 검색어 입력/정렬/재고 옵션을 다이얼로그 내부로 이동
- 검색 실행 시 최근 검색어 저장, 인기 검색어 카운트 업데이트

4. 탐색 탭과 카테고리 탭을 밀착 배치한다.
- `처음 시작 / 선물 / 신상 / 기본템 / 출근 룩 / 랭킹`
- 기존 카테고리 탭(`ALL/BEST/OUTER/TOP/BOTTOMS/SET CLOTHES/SHOES/BAG_ACC`)을 바로 아래 배치

## 쉬운 용어 설명
- 배너 캐러셀: 여러 이미지를 자동으로 넘겨 보여주는 영역.
- 검색 히스토리: 내가 이전에 입력했던 검색어 목록.
- 인기 검색어: 사용 빈도가 높은 검색어 목록.
- 다이얼로그: 화면 위에 잠깐 띄워서 입력/선택을 받는 창.
