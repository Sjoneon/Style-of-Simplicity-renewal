# 홈 헤더 검색/장바구니 위치 조정 + 검색 결과 카운트 조건 변경

## 무엇
- 상단 메뉴 아래(우측)에 `검색`, `장바구니` 버튼을 배치합니다.
- 홈 화면의 `탐색 탭: ... / 카테고리: ...` 안내 줄은 제거합니다.
- 검색 결과 개수는 검색을 실행했을 때만 보여주고, 문구는 `검색 결과 0개` 대신 `0개`처럼 숫자 중심으로 표시합니다.

## 왜
- 검색 UI가 본문을 크게 차지하면 상품 탐색이 답답해집니다.
- 헤더 우측의 빠른 액션(검색/장바구니)은 사용자가 어디서든 바로 접근하기 쉽습니다.
- 결과 카운트는 검색 맥락에서만 보이는 것이 정보 밀도가 높고, 문구를 줄이면 화면이 더 깔끔합니다.

## 언제
- 요청 반영 일시: 2026-03-03
- 적용 화면: 메인 목록(Home)

## 어떻게
- `frontend/src/components/AppLayout.jsx`
  - 상단 네비게이션 아래에 우측 정렬된 `검색`, `장바구니` 버튼 행을 추가합니다.
  - `검색` 버튼 클릭 시 홈으로 이동하면서 검색 다이얼로그를 열 수 있도록 URL 파라미터(`openSearch=1`)를 전달합니다.
- `frontend/src/pages/HomePage.jsx`
  - URL 파라미터를 감지해 검색 다이얼로그를 자동 오픈하고, 오픈 후 파라미터를 정리합니다.
  - 탐색/카테고리 안내 텍스트 줄을 제거합니다.
  - `hasSearched` 상태를 추가해, 검색어가 실제로 적용된 경우에만 결과 개수 영역을 렌더링합니다.
  - 결과 개수 텍스트를 `N개` 형태로 단순화합니다.

## 쉬운 용어
- 헤더: 화면 맨 위 고정 메뉴 영역
- 검색 다이얼로그: 검색어 입력용 팝업 창
- URL 파라미터: 주소 뒤에 붙는 옵션값(`?openSearch=1`)

## 완료 기준(Definition of Done)
- 홈 상단에서 `검색`/`장바구니` 버튼이 보이고 동작한다.
- `탐색 탭: ... / 카테고리: ...` 줄이 사라진다.
- 검색 실행 전에는 개수 표시가 안 보이고, 검색 후에는 `0개`처럼 숫자만 표시된다.
