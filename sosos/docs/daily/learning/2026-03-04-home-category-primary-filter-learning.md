# 2026-03-04 홈 탐색 구조 개편 학습 (카테고리 기본 + 이벤트 선택)

## 무엇
- 홈 상품 필터 구조를 `이벤트 탭 필수`에서 `카테고리 기본 + 이벤트 선택`으로 바꾼다.
- 이벤트 탭(처음 시작/선물/신상/기본템/사용자 추가 탭)은 선택하지 않으면 전체 카테고리 탐색이 가능해야 한다.
- 랭킹은 이벤트 성격과 다르므로 별도 모드(또는 정렬)로 분리해 동작시킨다.

## 왜
- 이벤트 탭은 기획전 성격이라 일반 탐색의 기본 축이 되면 사용성이 떨어진다.
- 사용자는 보통 `TOP/BOTTOMS` 같은 카테고리 중심으로 탐색하고, 필요할 때만 이벤트 필터를 건다.
- 필터 축을 분리하면 운영(탭 변경)과 사용자 탐색(카테고리 고정)을 동시에 만족할 수 있다.

## 언제
- 홈 탭을 동적으로 관리하게 된 이후, 일반 사용자 탐색 UX를 안정화할 때 적용한다.

## 어떻게
1. 이벤트 탭 선택값에 `all`(이벤트 필터 없음)을 추가하고 기본값으로 둔다.
2. 상품 필터에서 이벤트 조건은 `all`일 때 생략한다.
3. 카테고리 탭은 항상 전체 상품 기준으로 동작하게 유지한다.
4. 랭킹은 판매량 정렬이 적용되는 특수 모드로 유지하되, 이벤트 필터 없음 상태에서도 접근 가능하게 한다.

## 용어 쉬운 설명
- 이벤트 필터 없음(`all`): 처음 시작/선물 같은 탭을 아무것도 고르지 않은 상태.
- 카테고리 기본 탐색: TOP, BOTTOMS 같은 분류로 전체 상품을 바로 보는 방식.

## 완료 기준(Definition of Done)
- 홈 진입 후 이벤트 탭을 고르지 않아도 카테고리별 전체 상품 탐색이 가능하다.
