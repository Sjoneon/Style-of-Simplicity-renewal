# 2026-03-07 리뉴얼 브랜딩 텍스트 정정 학습

## 무엇
- 화면에서 `SOS 프로젝트`처럼 보이게 만드는 문구를 `SOS 리뉴얼 프로젝트` 맥락에 맞게 정정한다.

### 오늘 작업 대상 파일 경로
- `frontend/src/components/AppLayout.jsx`
- `frontend/src/pages/CustomerCenterPage.jsx`

### 완료 기준(DoD)
- 상단 브랜드와 고객센터 상단 문구가 리뉴얼 프로젝트 맥락으로 표시되면 완료.

## 왜
- 프로젝트 자체는 유지되어 있는데 텍스트가 혼동을 만들어 사용자 인식을 깨뜨린다.

## 언제
- 현재 화면 확인 직후 즉시 수정해야 한다.

## 어떻게
1. 헤더 브랜드명을 `SOS RENEWAL PROJECT`로 정정
2. 고객센터 상단 오버라인을 `SOS RENEWAL SUPPORT`로 정정
3. 프론트 린트로 정적 검증

## 쉬운 용어 설명
- 브랜딩 텍스트: 화면에서 서비스 이름/성격을 직접 보여주는 글자
