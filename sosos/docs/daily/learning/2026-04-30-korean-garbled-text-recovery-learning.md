# 2026-04-30 깨진 한글 주석/문구 복구 학습 메모

## 무엇
- `SellerService`에 남아 있던 깨진 한글(모지바케) 주석/예외 문구를 정상 한글로 복구했다.
- 작업 파일:
  - `sosos/src/main/java/com/prosos/sosos/service/SellerService.java`

## 왜
- 운영/디버깅 시 예외 메시지와 주석을 사람이 읽을 수 없으면 원인 파악과 후속 유지보수가 느려진다.
- 사용자/판매자에게 전달될 수 있는 메시지 품질도 떨어진다.

## 언제
- 문자열에 `?` 기반 깨짐 패턴, 의미 불명 한글/한자 혼합 패턴이 보일 때 즉시 정리한다.

## 어떻게
1. 깨짐 패턴 검색
- `rg -n "\\?[가-힣]"`로 의심 구간을 빠르게 식별
2. 문구 일괄 치환
- 기존 로직은 유지하고 주석/메시지 텍스트만 정상 한국어로 교체
3. 잔여 깨짐 재검사
- `U+FFFD`, `?[가-힣]`, 이상 유니코드 구간 재검색
4. 컴파일 검증
- `cd sosos && .\\mvnw.cmd -q -DskipTests compile`

## 완료 기준(Definition of Done)
- `SellerService`에서 깨진 한글 주석/문구가 사라지고 컴파일이 정상 통과한다.
