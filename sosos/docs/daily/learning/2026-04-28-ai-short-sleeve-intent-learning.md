# 2026-04-28 학습 메모 - 반팔/반바지 의도 인식 보강

## 무엇
- 목표:
  - `반팔 추천해봐`, `반바지 추천해줘` 같은 짧은 요청도 패션 의도로 정확히 인식한다.
  - `반팔`은 상의(TOP), `반바지`는 하의(BOTTOM)로 해석해 추천 필터에 반영한다.

## 왜
- 기존 설명/구현의 누락:
  - 누락 1: 패션 의도 단어 목록에 `반팔`/`반바지`가 빠져 있어 비패션 요청으로 오판될 수 있었다.
  - 누락 2: 카테고리 의도 파서에서도 `반팔`/`반바지`를 직접 해석하지 않아 TOP/BOTTOM 우선 추천이 약했다.

## 언제
- 사용자가 짧게 카테고리만 입력하는 요청(예: `반팔 추천`)을 자주 보낼 때 즉시 적용한다.
- 챗봇이 "의류 코디 추천만 지원" 오류를 잘못 반환할 때 우선 점검한다.

## 어떻게
- 쉬운 용어 설명:
  - 의도 인식: 사용자가 무엇을 원했는지 문장에서 분류하는 과정
  - 카테고리 매핑: 단어를 TOP/BOTTOM 같은 내부 분류로 바꾸는 처리
- 구현 순서:
  1. 패션 의도 단어(FASHION_TERMS)에 `반팔`, `긴팔`, `반바지`, `긴바지`, `민소매` 추가
  2. 카테고리 단어(UPPER/BOTTOM_TERMS)에 `반팔`/`반바지` 등 추가
  3. 단위 테스트로 `반팔 추천해봐` 요청이 차단되지 않고 TOP 추천으로 이어지는지 검증
