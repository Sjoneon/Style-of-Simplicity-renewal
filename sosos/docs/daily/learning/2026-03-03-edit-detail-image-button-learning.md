# 상품 수정 모달에 상세이미지 교체 추가

## 무엇
- 슈퍼관리자 상품 수정 모달에 `상세 이미지 교체` 파일 선택 버튼을 추가한다.

## 왜
- 현재는 대표 이미지 교체만 가능하고 상세 이미지 교체 UI가 없어 기능이 누락되어 보인다.

## 언제
- 요청 반영 일시: 2026-03-03

## 어떻게
- `frontend/src/pages/SellerDashboardPage.jsx` 수정
  - 수정 모달에 `descriptionImageFile` 선택 버튼 추가
  - 대표/상세 선택 파일명을 함께 표시
  - 기존 업데이트 API 전달 로직(`descriptionImageFile`)은 유지

## 쉬운 용어
- 수정 모달: 상품 `수정` 버튼 클릭 시 뜨는 팝업
- 상세 이미지: 상품 설명 하단 등에 쓰는 추가 이미지

## 완료 기준(Definition of Done)
- 수정 모달에서 대표 이미지와 상세 이미지를 각각 교체할 수 있다.
