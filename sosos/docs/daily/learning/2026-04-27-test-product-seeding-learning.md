# 2026-04-27 학습 메모 - 테스트 상품 대량 세팅

## 무엇
- 목표:
  - 로컬 사이트에 테스트용 의류 상품을 여러 개 추가한다.
  - 상품마다 이름/카테고리/가격/재고/설명/이미지를 포함한다.
  - 세팅 완료 후 소비자/판매자 접속 주소를 다시 확인한다.

## 왜
- 현재 상품이 1개뿐이면 목록/상세/장바구니/검색/정렬 테스트 범위가 매우 제한된다.
- 배포 전 UX 점검을 위해 최소 10~20개 이상의 샘플 상품이 필요하다.
- 수동 등록 반복은 시간이 오래 걸리므로 자동화 스크립트가 필요하다.

## 언제
- AWS 배포 전 로컬 기능 점검 단계에서 사용한다.
- 디자인/필터/정렬/장바구니 회귀 테스트 전에 먼저 실행한다.

## 어떻게
- 쉬운 용어 설명:
  - 시딩(Seeding): 테스트를 위해 초기 데이터를 한 번에 넣는 작업
  - 스모크 확인: 핵심 기능이 최소한 정상 동작하는지 빠르게 확인하는 테스트
- 실행 순서:
  1. 백엔드 상품 등록 API(`/api/v1/products`) 요청 형식 확인
  2. 등록용 이미지 파일 경로 확보
  3. 자동 등록 스크립트 작성 후 20개 상품 등록
  4. 등록 결과 개수/샘플 응답 확인
  5. 소비자/판매자 주소 재안내

## 오늘 작업 대상 파일 경로
- `scripts/seed-test-products.ps1` (신규)
- `sosos/docs/daily/learning/README.md`
- `sosos/docs/daily/2026-04-27.md`

## 완료 기준(Definition of Done)
- 로컬 상품 목록이 1개에서 목표 개수(기본 20개 이상)로 증가하고, API 응답으로 정상 조회되며, 소비자/판매자 접속 주소를 다시 전달한다.
