# 슈퍼관리자 운영 대시보드 확장 (상품/주문/매출/Q&A)

## 무엇
- 슈퍼관리자 대시보드를 운영 업무 중심으로 확장합니다.
- 핵심 기능 4가지를 제공합니다.
  1) 상품 등록/수정/삭제
  2) 주문·배송 상태 확인 및 처리
  3) 매출/운영 현황 요약
  4) 사용자 Q&A 답변 처리

## 왜
- 현재 대시보드는 조회 위주라 실제 쇼핑몰 운영 업무를 처리하기 어렵습니다.
- 관리자 화면은 업무(등록/처리/응답)가 바로 가능한 구조여야 운영 효율이 높아집니다.

## 언제
- 요청 반영 일시: 2026-03-03
- 적용 범위: `frontend` 관리자 대시보드

## 어떻게
- API 서비스 확장
  - `frontend/src/services/productApi.js`: 상품 등록/수정/삭제 API 추가
  - `frontend/src/services/inquiryApi.js`: 문의 목록 조회/답변/수정/삭제 API 추가
- 화면 확장
  - `frontend/src/pages/SellerDashboardPage.jsx`를 운영 탭 구조로 재구성
  - 탭: `운영 요약`, `상품 관리`, `주문·배송`, `Q&A`
- 데이터 연결
  - 상품 목록, 판매 주문 목록, 문의 목록을 로딩해 KPI/목록/처리 액션 연결

## 쉬운 용어
- KPI: 운영 상태를 빠르게 보는 핵심 숫자(예: 총 매출, 미답변 문의)
- 탭: 한 화면 안에서 영역을 바꾸는 버튼
- 처리 액션: 주문 상태 변경, 문의 답변 저장 같은 실제 실행 버튼

## 완료 기준(Definition of Done)
- 슈퍼관리자 화면에서 상품 등록/수정/삭제가 가능하다.
- 주문 상태를 화면에서 변경할 수 있다.
- 문의 목록을 보고 답변 등록/수정이 가능하다.
- 운영 요약 카드에서 핵심 현황(매출/주문/문의)을 확인할 수 있다.
