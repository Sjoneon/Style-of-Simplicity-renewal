# 2026-03-04 학습 메모 - 장바구니 수량 변경 토스트 제거 및 재렌더 체감 완화

## 무엇
- 장바구니 수량 변경 성공 토스트를 제거한다.
- 수량 변경 시 `장바구니 주문하기` 영역이 함께 깜빡이는 체감을 줄이기 위해 상태 관리를 분리한다.
- 대상 파일:
  - `frontend/src/pages/CartPage.jsx`
- 완료 기준(Definition of Done):
  - 수량 변경 후 좌하단 성공 토스트가 뜨지 않는다.
  - 수량 변경 시 주문 버튼이 비활성화/재활성화되며 깜빡이지 않는다.

## 왜
- 성공 토스트는 반복 조작(+- 클릭)에서 정보 가치가 낮고 화면만 산만하게 만든다.
- 기존 `processing` 단일 상태는 수량 변경에도 전체 액션 버튼 상태를 바꿔, 부분 갱신이어도 전체가 재로딩처럼 보이게 만든다.

## 언제
- 장바구니에서 수량을 여러 번 연속 조절할 때.
- 주문 버튼을 바로 눌러야 하는 상황에서 수량 변경 UI 반응이 거슬릴 때.

## 어떻게
1. `processing` 단일 상태를 제거한다.
2. 액션별 상태를 분리한다.
   - `isPurchasing`
   - `removingCartItemId`
   - `changingCartItemId`
3. 수량 변경 성공 시 `toastMessage`를 세팅하지 않는다.
4. 주문 버튼 비활성화 조건에서 수량 변경 상태를 제외해 주문 영역 깜빡임을 제거한다.

## 쉬운 용어 설명
- `재렌더`: React가 상태 변경 후 화면을 다시 계산해 그리는 과정.
- `상태 분리`: 하나의 공용 상태 대신 기능별로 상태를 나누어 영향 범위를 줄이는 방식.
