# SellerService 깨진 한글 복구 학습 (2026-05-07)

## 무엇
- `sosos/src/main/java/com/prosos/sosos/service/SellerService.java`에 있는 깨진 한글 주석/문구를 복구한다.
- 깨진 한글 탐지 스크립트 기준 오류(`question-before-korean`, `compatibility-ideograph`)를 0건으로 만든다.

## 왜
- 깨진 주석/예외 메시지는 유지보수성과 운영 가독성을 크게 떨어뜨린다.
- 사용자/운영자 노출 문구가 깨져 있으면 기능은 동작해도 신뢰도를 해친다.

## 언제
- 배포 전 최종 품질 점검 단계에서 반드시 선행되어야 한다.
- 한글 주석/문구를 추가한 뒤 인코딩 문제가 누적된 상태를 정리할 때 필요하다.

## 어떻게
1. 깨진 한글 검사 스크립트로 위치를 확정한다.
2. 해당 라인의 주석/문구를 문맥에 맞는 정상 한국어로 치환한다.
3. 변경 파일 기준 깨진 한글 패턴 재검사로 즉시 확인한다.
4. 백엔드 컴파일로 문법/타입 오류가 없는지 검증한다.

## 쉬운 용어 설명
- 인코딩 깨짐: 글자를 저장/읽는 규칙이 맞지 않아 문자가 이상하게 보이는 현상.
- 재검수: 수정 후 같은 검사 절차를 다시 돌려서 문제가 사라졌는지 확인하는 과정.

## 완료 기준 (DoD)
- `SellerService.java`에서 깨진 한글 패턴이 0건이다.
- `mvnw -DskipTests compile`이 성공한다.
