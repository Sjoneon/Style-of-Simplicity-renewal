# 2026-04-28 학습 메모 - 판매자 상품 등록/수정 모달 흐름 전환

## 무엇
- 목표:
  - 상품 관리 화면에서 인라인 상품 등록 폼을 제거하고, `상품 등록` 버튼 클릭 시 모달에서 등록하도록 변경한다.
  - 등록 취소 시 작성 중인 내용을 버리고 목록 중심으로 돌아가게 한다.
  - 수정은 기존처럼 모달에서 수행하되 흐름을 목록 중심으로 정리한다.
  - 화면 문구 `슈퍼관리자 대시보드`를 `판매자 대시보드`로 변경한다.

## 왜
- 기존 설명/구현의 누락:
  - 누락 1: 등록 폼이 목록 위에 항상 열려 있어, 등록 상품 수정/삭제 시 스크롤 이동이 번거로웠다.
  - 누락 2: 등록을 시작했다가 취소하고 싶을 때 “닫기/취소” 흐름이 명확하지 않았다.
  - 누락 3: 판매자 화면인데 상단 타이틀이 `슈퍼관리자`로 표시되어 역할 명칭이 혼동됐다.

## 언제
- 판매자 운영 화면에서 등록보다 기존 상품 관리(수정/삭제) 빈도가 높아진 시점에 적용한다.
- 관리자 탭 UX 개선 작업에서 목록 우선 구조가 필요할 때 사용한다.

## 어떻게
- 쉬운 용어 설명:
  - 인라인 폼: 페이지 본문에 항상 펼쳐져 있는 입력 영역
  - 모달(Dialog): 버튼을 누르면 위에 뜨는 팝업 입력 창
- 구현 순서:
  1. 상품 목록 카드 헤더에 `상품 등록` 버튼 추가
  2. 등록 폼을 모달로 이동하고, 취소 시 폼 초기화 + 모달 닫기 처리
  3. 등록 성공 시 모달 자동 닫기 + 목록 새로고침 유지
  4. 대시보드 명칭 문구(`슈퍼관리자`)를 `판매자`로 교체
  5. 프론트 린트로 정적 검증
