# 2026-04-28 학습 메모 - AI 추천 안전 가드레일 보강

## 무엇
- 목표:
  - 외부 쇼핑몰 유도(예: 무신사 검색) 요청을 의류 추천으로 처리하지 않고 차단한다.
  - 비인격화/혐오/폭력성 문맥(예: 노예 관련 표현) 요청을 차단한다.
  - 계절/상황/카테고리 의도를 상품명·설명·키워드에서 함께 해석해 추천 정확도를 높인다.

## 왜
- 기존 설명/구현의 누락:
  - 누락 1: `무신사` 같은 외부 쇼핑몰/검색 유도 문구가 답변에 반영될 수 있었다.
  - 누락 2: `노예` 같은 비인격화 표현이 포함돼도 `옷 추천` 단어가 있으면 추천이 진행됐다.
  - 누락 3: 판매자 키워드가 부족한 경우, 계절/상황 의도를 이름/설명에서 보강하는 점수 규칙이 약했다.

## 언제
- AI 챗봇이 의류 추천 범위를 벗어나 외부 사이트/유해 문맥을 수용하는 순간 즉시 적용한다.
- 배포 전 안전성 점검에서 “차단되어야 할 입력” 시나리오를 통과해야 할 때 사용한다.

## 어떻게
- 쉬운 용어 설명:
  - 가드레일: AI가 벗어나면 안 되는 안전선
  - 차단 응답: 추천 대신 “지원하지 않는다”를 반환하는 안전 응답
  - 의도 점수: 사용자가 원하는 조건(여름/결혼식/상의 등)과 상품 정보가 맞을수록 점수를 높이는 방식
- 구현 순서:
  1. 입력 텍스트에서 `외부 쇼핑몰 유도`와 `유해 문맥`을 먼저 감지해 즉시 차단
  2. Gemini 응답에도 2차 필터를 걸어 외부 쇼핑몰/검색/링크 문구가 나오면 로컬 안전 응답으로 대체
  3. 계절/상황 의도(예: 여름/결혼식)를 상품명·설명·키워드에 교차 매칭해 점수 보강
  4. 단위 테스트로 차단/통과 경계를 고정
