# 2026-04-28 학습 메모 - 반복 답답 어투 대응 응답 추가

## 무엇
- 목표:
  - 사용자가 비슷한 질문을 답답한 어투로 반복(약 4회)하면 사과 + 현재 미흡함 + 현재 가능한 활용법을 안내한다.
  - 같은 입력이 계속 쌓일 때 무한 반복 추천 대신 완충 응답으로 사용자 경험을 안정화한다.

## 왜
- 기존 설명/구현의 누락:
  - 누락 1: 반복 실패 상황에서도 매번 동일 추천 흐름으로 들어가 사용자가 더 답답해질 수 있었다.
  - 누락 2: 시스템 한계를 명시하지 않아 “왜 계속 안 되는지”를 사용자가 알기 어려웠다.

## 언제
- 동일/유사 질문이 답답한 어투로 연속 입력될 때 즉시 적용한다.
- 운영 중 반복 문의가 늘어나는 구간에서 우선 점검한다.

## 어떻게
- 쉬운 용어 설명:
  - 반복 감지: 이전 메시지와 현재 메시지가 충분히 비슷한지 확인하는 처리
  - 세션 상태: 사용자별로 브라우저 세션 안에 임시 카운트를 저장하는 방식
- 구현 순서:
  1. API 컨트롤러에서 세션 기준 반복 상태(기준 문장/횟수) 저장
  2. 답답 어투 키워드 + 유사도 기준을 만족하면 카운트 증가
  3. 4회 도달 시 사과/미흡/가능 활용법 안내 응답 반환
  4. 컨트롤러 단위 테스트로 4회 트리거와 비트리거 케이스 고정
