# 판매자 대시보드 하위 메뉴 그레이 선택 스타일 학습 (2026-06-16)

## 무엇
- 판매자 대시보드 좌측 메뉴의 하위 메뉴 선택 표시에서 검은 왼쪽 강조선을 제거한다.
- 선택된 하위 메뉴는 밝은 그레이 배경만으로 표시한다.

## 왜
- 부모 메뉴는 검은 배경, 하위 메뉴는 그레이 배경으로 구분하는 것이 더 자연스럽다.
- 하위 메뉴 옆에 검은 선이 남으면 부모 메뉴와 시각적으로 다시 붙어 보일 수 있다.

## 언제
- 하위 메뉴를 선택했을 때 검은 강조선이 너무 강하게 보여 메뉴가 답답해 보일 때 적용한다.

## 어떻게
1. `SellerDashboardSideNav.jsx`의 하위 메뉴 선택 스타일에서 검은 `boxShadow`를 제거한다.
2. 선택 배경은 밝은 회색으로 유지한다.
3. 프론트 린트/빌드와 한글 깨짐 검사를 실행한다.

## 쉬운 용어
- 하위 메뉴: `메인 배너 관리`, `홈 탐색 관리`처럼 큰 메뉴 안에 들어 있는 메뉴다.
- 선택 표시: 현재 선택된 메뉴임을 알려주는 배경색, 선, 글자색 같은 화면 표현이다.
