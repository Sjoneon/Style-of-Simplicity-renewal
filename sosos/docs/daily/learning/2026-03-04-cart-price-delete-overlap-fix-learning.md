# 2026-03-04 학습 메모 - 장바구니 가격/삭제 버튼 겹침 수정

## 무엇
- 장바구니 목록 한 줄에서 `가격 영역`과 `삭제 버튼`이 서로 겹치는 레이아웃 문제를 수정한다.
- 대상 파일:
  - `frontend/src/pages/CartPage.jsx`
- 완료 기준(Definition of Done):
  - 장바구니 행에서 가격과 삭제 버튼이 겹치지 않는다.
  - 데스크톱/모바일 너비에서 텍스트가 눌리거나 버튼이 덮이지 않는다.

## 왜
- 현재 코드는 `ListItem`의 `secondaryAction`(오른쪽 절대 위치 버튼)과 가격 `Typography`를 같은 행에 함께 둔다.
- `secondaryAction`은 위치가 고정(absolute)이라, 오른쪽에 추가된 가격 텍스트와 충돌할 수 있다.
- 사용자 입장에서 클릭 영역이 겹치면 오작동/가독성 저하가 바로 발생한다.

## 언제
- 증상: 장바구니 화면에서 상품 단가/합계가 보이는 줄의 오른쪽에서 삭제 버튼과 가격 표시가 겹쳐 보임.
- 조건: 항목명이 길거나 화면 너비가 줄어들 때 더 쉽게 재현됨.

## 어떻게
1. `secondaryAction` 사용을 제거한다.
2. 행 우측을 전용 `Stack`으로 분리해 `가격 + 삭제 버튼`을 같은 컬럼으로 배치한다.
3. 왼쪽 상품 정보(`ListItemText`)에 `pr`(오른쪽 여백)을 부여해 우측 영역과 안전 간격을 확보한다.
4. 화면 폭이 좁아져도 구조가 깨지지 않게 우측 컬럼을 `flexShrink: 0`으로 고정한다.

## 쉬운 용어 설명
- `absolute(절대 위치)`: 주변 요소와 상호 배치 계산을 거의 하지 않고, 특정 위치에 덮어놓는 방식.
- `Stack`: 요소를 세로/가로로 정렬해 간격을 관리하는 MUI 레이아웃 컴포넌트.
