# 2026-03-07 사용자/관리자 로그인 진입 분리 보강 학습

## 무엇
- 사용자 로그인 페이지(`/auth`)에서 `슈퍼관리자 로그인` 버튼을 제거한다.
- 사용자 로그인 폼은 이메일 형식만 허용해 관리자(사업자번호) 로그인 시도를 차단한다.

### 오늘 작업 대상 파일 경로
- `frontend/src/pages/AuthPage.jsx`
- `sosos/docs/daily/2026-03-07.md`
- `sosos/docs/work-summary.md`

### 완료 기준(DoD)
- 사용자 로그인 페이지에 관리자 진입 버튼이 보이지 않고, 이메일 형식이 아닌 아이디로는 로그인 요청이 전송되지 않으면 완료.

## 왜
- 관리자 로그인은 일반 사용자 UX와 분리된 진입점(`/admin/login`)으로 유지해야 한다.
- 사용자 로그인 화면에서 관리자 경로가 보이면 역할 경계가 흐려지고 운영 정책과 충돌한다.

## 언제
- 사용자 피드백으로 UX 정책 위반이 확인되었기 때문에 즉시 수정한다.

## 어떻게
1. `AuthPage`에서 관리자 버튼 UI 제거
2. 로그인 submit 전에 이메일 형식 검증 추가
3. 검증 실패 시 사용자 안내 메시지 표시 후 요청 중단
4. 린트/빌드/컴파일로 정적 검증

## 쉬운 용어 설명
- 진입점 분리: 사용자와 관리자 로그인 화면을 역할별로 따로 운영하는 방식
