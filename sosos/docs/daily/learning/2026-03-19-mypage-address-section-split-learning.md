# 2026-03-19 MyPage 배송지 섹션 분리 학습

## 무엇
마이페이지에서 `계정 관리` 안에 섞여 있던 배송지 수정 기능을 별도 섹션으로 분리한다.
- 5번: 배송지 관리
- 6번: 계정 관리

변경 대상 파일
- `frontend/src/pages/MyPagePage.jsx`

완료 기준(DoD)
- `배송지 관리` 섹션이 5번으로 독립된다.
- `계정 관리` 섹션은 6번으로 변경된다.
- 배송지 수정 API(`updateMyAddress`)는 5번 섹션에서 동작한다.
- 계정 관리 섹션에서 주소 입력 UI는 제거된다.

## 왜
계정 정보(이름/연락처/비밀번호)와 배송지 정보는 사용 목적이 다르다.
- 계정 정보: 로그인/보안/개인 식별
- 배송지 정보: 주문 수령 주소 관리

같은 섹션에 섞이면 사용자가 기능 위치를 기억하기 어렵고 화면이 복잡해진다.

## 언제
- 마이페이지를 접기/펼치기 구조로 정리한 이후
- 사용자가 배송지를 별도 항목으로 분리해달라고 요청한 시점

## 어떻게
1. 섹션 순서를 `1 주문 -> 2 혜택 -> 3 찜/최근본 -> 4 리뷰/문의 -> 5 배송지 -> 6 계정관리`로 조정한다.
2. 기존 계정관리의 배송지 폼을 5번 섹션으로 이동한다.
3. 계정관리의 회원정보 수정은 이름/연락처 중심으로 유지하고, 주소는 배송지 섹션 데이터로 관리한다.
4. 저장 API와 에러/성공 메시지 흐름은 기존 로직을 재사용한다.
