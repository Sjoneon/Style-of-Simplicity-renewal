# 2026-03-19 마이페이지 배송지 카카오 주소검색 연동 학습

## 무엇
마이페이지 `5. 배송지 관리`를 카카오 우편번호 서비스 기반으로 바꾼다.

작업 범위
- 카카오 우편번호 검색 팝업 연동
- 배송지 입력을 `우편번호 + 기본 주소 + 상세 주소` 3필드로 분리
- 저장 시에는 하나의 문자열 주소로 합쳐 기존 API(`PUT /api/v1/users/me/address`)로 전송

작업 대상 파일
- `frontend/src/pages/MyPagePage.jsx`
- `frontend/src/utils/loadKakaoPostcode.js` (신규)

완료 기준(DoD)
- 사용자가 `주소 검색` 버튼으로 카카오 우편번호 팝업을 열 수 있다.
- 주소 선택 시 우편번호/기본주소가 자동 입력된다.
- 상세주소는 사용자가 하단 입력칸에 직접 입력 가능하다.
- `배송지 저장` 클릭 시 기존 백엔드 API로 정상 저장된다.

의사결정 1줄
- 백엔드 스키마는 바꾸지 않고, 프론트에서 `우편번호+기본주소+상세주소`를 합쳐 기존 `address` 필드에 저장한다. 이유: 현재 API와 DB 호환을 유지하기 위해서다.

## 왜
현재는 배송지 입력이 단일 텍스트라 주소 정확도가 낮고 오입력 가능성이 크다.
실무 쇼핑몰에서는 우편번호 검색으로 기본주소를 고정하고, 상세주소만 사용자가 입력하도록 분리해 오류를 줄인다.

## 언제
- 마이페이지 MVP에서 배송지 관리는 이미 동작 중
- 사용자 요구사항(카카오 주소 검색 + 상세주소 별도 입력) 반영 시점

## 어떻게
1. 카카오 우편번호 스크립트를 동적으로 로드하는 유틸을 추가한다.
2. 배송지 폼 상태를 `postcode/address/detailAddress`로 변경한다.
3. `주소 검색` 버튼에서 카카오 팝업을 열고 선택 결과를 폼에 반영한다.
4. 저장 시 3필드를 합쳐 단일 문자열 주소로 만들어 API 호출한다.
5. 프론트 린트/빌드로 검증한다.
