# 2026-03-04 탐색 탭 삭제 후 순서 자동 정돈 학습

## 무엇
- 탐색 탭을 삭제하면 남은 탭의 노출 순서(`displayOrder`)를 0부터 연속 숫자로 자동 정리한다.

## 왜
- 운영자가 탭을 삭제한 뒤에도 순서가 중간에 비면(예: 0,1,2,3,5) 관리 화면이 헷갈린다.
- 홈 탭 순서는 연속 값으로 유지해야 운영/디버깅이 쉽다.

## 언제
- 판매자가 탭 추가/삭제를 반복해서 홈 탭을 운영할 때.

## 어떻게
1. `DiscoveryTabService`에 순서 정규화 메서드를 추가한다.
2. 탭 삭제 후 정규화 메서드를 호출한다.
3. 필요 시 조회 시점에도 정규화해서 기존 데이터의 빈 순서를 자동 복구한다.

## 용어 쉬운 설명
- displayOrder: 탭이 화면에 보이는 순서 번호.
- 정규화: 순서 번호를 0,1,2,3처럼 끊김 없이 다시 맞추는 작업.

## 완료 기준(Definition of Done)
- 탭 삭제 직후 관리 화면에서 남은 탭 순서가 끊김 없이 연속 숫자로 보인다.
