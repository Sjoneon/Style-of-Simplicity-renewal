# 2026-04-29 학습 메모 - 상품 리스트 밀도/미리보기 1차 적용

## 무엇
- 목표:
  - 메인 홈 상품 카드가 너무 크게 보이는 문제를 줄이기 위해 카드 밀도를 높인다.
  - 리스트에서 더 빨리 판단할 수 있도록 핵심 정보 배치를 개선한다.
  - 카드 hover 시 상세 이미지(2번째 이미지) 미리보기를 제공한다.
  - 소비자 리스트에는 불필요한 운영성 안내문구를 숨기고, 브랜드/찜 중심 카드로 단순화한다.
  - 세일 가격을 판매자/소비자 양쪽에서 다룰 수 있도록 `정상가(originalPrice)` 기반을 추가한다.

## 왜
- 기존 누락:
  - 데스크톱 기준 카드 폭이 넓어 한 화면 비교 수가 적었다.
  - 리스트에서 상품 비교에 필요한 정보가 제한적이었다.
  - 상세 이미지를 상세페이지로 들어가야만 확인 가능해 탐색 효율이 떨어졌다.
  - 소비자 화면에 `상세 이미지 미등록` 같은 운영성 메시지가 노출되어 구매 맥락과 맞지 않았다.
  - 카드 내 `상세 보기/바로담기` 버튼이 과해 클릭 동선이 분산됐다.
  - 브랜드 정보/찜 진입점/세일 가격 표현이 없어 탐색 감각이 약했다.

## 언제
- 홈 상품 탐색 효율 개선이 필요할 때, 상세페이지 진입 전 판단 속도를 높이고 싶을 때 적용한다.

## 어떻게
- 쉬운 용어 설명:
  - 카드 밀도: 한 화면에 보이는 상품 카드 수
  - hover 미리보기: 마우스를 올렸을 때 다른 이미지로 잠깐 바꿔 보여주는 기능
- 구현 순서:
  1. 상품 그리드를 데스크톱 기준 5열까지 보이도록 재조정
  2. 카드 높이/폰트/정보 배치를 축소형으로 정리
  3. `descriptionImageUrl`이 있으면 hover 시 2번째 이미지로 전환
  4. 소비자 카드는 브랜드/상품명/가격/찜 중심으로 단순화하고, 상세/담기 버튼 제거
  5. 홈 카드 찜 토글(로그인/권한 체크 포함) 연결
  6. 판매자 등록/수정 모달에 정상가 입력 추가, 소비자 카드/상세에 할인율/정상가 표시
  7. 판매자 상품 등록 모달에 상세 이미지 미등록 경고 UI 추가
  8. 프론트 린트 + 백엔드 테스트 실행으로 정적 검증
