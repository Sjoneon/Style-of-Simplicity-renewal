# 2026-03-19 실수 방지 실행 가드 + 마이페이지 MVP 학습

## 무엇
- 로컬 리뉴얼 프로젝트에서만 안전하게 서버를 실행하도록 실행 가드를 추가한다.
- `마이페이지`를 플레이스홀더에서 `내 정보 + 내 주문 목록`이 보이는 MVP로 구현한다.

### 오늘 작업 대상 파일 경로
- `scripts/start-renewal-dev.ps1` (신규)
- `frontend/src/pages/MyPagePage.jsx`

### 완료 기준(DoD)
- 실행 가드가 잘못된 경로/브랜치/remote 상태를 감지하면 실행을 중단하고, 정상 상태에서는 프론트/백엔드 서버를 시작한다.
- 마이페이지에서 사용자 계정 기준 내 정보 카드와 주문 목록(상태 요약/필터 포함)이 정상 표시된다.

## 왜
- 브랜치/경로 혼선이 생기면 “만든 코드가 안 보이는” 문제가 다시 발생할 수 있다.
- 현재 마이페이지는 안내 문구만 있어 사용자 관점 핵심 정보 확인이 불가능하다.

## 언제
- 고객센터 MVP 이후, 마이페이지 착수 전환 시점에 바로 적용한다.

## 어떻게
1. 실행 가드 스크립트 작성
- 프로젝트 루트 여부 확인
- 현재 브랜치 `main` 확인
- push remote가 `renewal`인지 확인
- 포트 충돌 정리 후 서버 실행

2. 마이페이지 MVP 구현
- 사용자 기본 정보 카드(이름/이메일/계정유형)
- 주문 현황 요약 칩(전체/결제완료/배송중/취소/반품/교환)
- 주문 목록 필터(전체 + 상태별)
- 판매자 계정 접근 시 판매자용 안내 카드 분기

3. 최소 검증
- 프론트 lint/build
- 백엔드 compile

## 쉬운 용어 설명
- 실행 가드: 실행 전에 위험 조건을 먼저 검사해서 실수를 막아 주는 안전장치
- MVP: 꼭 필요한 최소 기능만 먼저 동작하게 만든 버전
