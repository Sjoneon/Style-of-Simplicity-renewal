# 2026-04-27 학습 메모 - AI 추천 의도 필터 보강

## 무엇
- 목표:
  - AI 추천에서 사용자 의도(예: 상의/외투/바지 중심)를 더 정확히 반영한다.
  - 의류만 요청한 경우 가방/신발/액세서리 추천을 제외한다.
  - 이미 상세 조건을 준 사용자가 같은 안내 문구를 반복해서 보지 않게 한다.

## 왜
- 실제 피드백에서 `상의/외투/바지` 요청에도 `Bag`, `Loafer`가 추천되는 문제가 발생했다.
- 기존 로직은 토큰 유사도 중심이라 "카테고리 제외 의도"를 강제하지 못했다.
- 추천 답변 말미에 같은 질문을 반복해 대화 품질이 떨어졌다.

## 언제
- AI 추천 기능 QA 단계에서 사용자 의도 불일치가 확인됐을 때 즉시 적용한다.
- 배포 전 추천 품질 점검(카테고리 필터, 예산/체형 입력 반영) 구간에서 재검증한다.

## 어떻게
- 쉬운 용어 설명:
  - 의도 필터: 사용자가 원한 범위만 통과시키는 1차 관문
  - 비의류 제외: 가방/신발/액세서리처럼 요청하지 않은 품목을 후보에서 제거
  - 회귀 테스트: 같은 문제가 다시 생기지 않도록 자동 검증을 추가하는 것
- 구현 순서:
  1. 사용자 문장에서 요청 카테고리와 비의류 제외 의도 파싱
  2. 추천 점수 계산 전 의도와 맞지 않는 상품 제거
  3. 상세 조건을 이미 말했는지 판단해 안내 문구 분기
  4. 단위 테스트로 재발 방지
