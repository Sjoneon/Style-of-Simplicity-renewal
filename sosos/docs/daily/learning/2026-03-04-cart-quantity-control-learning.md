# 2026-03-04 학습 메모 - 장바구니 수량 조절 기능

## 무엇
- 장바구니 화면에서 상품 수량을 `삭제 후 재담기` 없이 바로 변경할 수 있게 만든다.
- 대상 파일:
  - `sosos/src/main/java/com/prosos/sosos/service/UserService.java`
  - `sosos/src/main/java/com/prosos/sosos/controller/api/v1/ProductApiController.java`
  - `frontend/src/services/productApi.js`
  - `frontend/src/pages/CartPage.jsx`
- 완료 기준(Definition of Done):
  - 장바구니 항목에서 `- / +`로 수량을 즉시 변경할 수 있다.
  - 수량 1 미만은 막고, 재고보다 큰 수량도 막는다.
  - 변경 후 항목 합계/총 결제 금액이 올바르게 갱신된다.

## 왜
- 현재는 수량을 바꾸려면 삭제 후 다시 담아야 해서 클릭 횟수가 많고 실수 가능성이 높다.
- 장바구니는 주문 직전 화면이라, 수량 조절은 기본 핵심 UX다.

## 언제
- 같은 상품을 여러 개 담은 뒤 수량을 조금만 줄이거나 늘리고 싶을 때.
- 옵션 상품(사이즈 선택 상품)도 동일하게 수량 변경이 필요할 때.

## 어떻게
1. 백엔드에 `cartItemId` 기준 수량 변경 API를 추가한다.
2. 서비스 레이어에서 로그인 사용자 소유 항목인지 확인한다.
3. 일반 상품/옵션 상품을 나눠 현재 재고를 검증한다.
4. 프론트 장바구니 항목에 `- / +` 컨트롤을 추가해 API와 연결한다.
5. 변경 성공 시 화면 상태(수량/합계/총액)를 즉시 갱신한다.

## 쉬운 용어 설명
- `cartItemId`: 장바구니에 담긴 “한 줄” 자체의 고유 번호.
- `재고 검증`: 사용자가 요청한 수량이 실제 남은 수량보다 크지 않은지 확인하는 검사.
