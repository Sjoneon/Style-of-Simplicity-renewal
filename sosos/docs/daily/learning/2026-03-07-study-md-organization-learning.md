# 2026-03-07 공부용 Markdown 정리 학습

## 무엇
- `sosos/docs/daily/learning/` 폴더의 공부용 문서를 규칙 기준으로 정리한다.
- 파일명 규칙 불일치를 통일하고, 목록을 한 번에 찾을 수 있는 인덱스 문서를 만든다.

### 오늘 작업 대상 파일 경로
- `sosos/docs/daily/learning/README.md` (신규)
- `sosos/docs/daily/learning/2026-03-03-header-search-result-count-update-learning.md` (이름 통일)
- `sosos/docs/daily/2026-03-03.md` (참조 경로 수정)
- `sosos/docs/daily/README.md` (폴더 안내 보강)

### 완료 기준(DoD)
- 공부용 문서 전체를 날짜/주제 기준으로 한 파일에서 찾을 수 있고, 링크가 모두 정상 동작하면 완료.

## 왜
- 파일 수가 늘어나면서 특정 학습 문서를 빠르게 찾기 어려워졌다.
- 파일명 규칙이 섞여 있으면 검색/자동화 시 누락이 생길 수 있다.

## 언제
- 마이페이지 구현 착수 전에 문서 기반을 정리할 때 적용한다.

## 어떻게
1. `learning/` 문서 전수 점검(형식/중복/파일명 규칙)
2. 규칙 불일치 파일명 1건 통일
3. 날짜순 인덱스(`learning/README.md`) 생성
4. 기존 참조 링크 경로 보정

## 쉬운 용어 설명
- 인덱스: 여러 문서를 한 페이지에서 빠르게 찾아 들어갈 수 있게 정리한 목록
