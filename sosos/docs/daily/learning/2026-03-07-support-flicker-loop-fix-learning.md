# 2026-03-07 고객센터 401 자동이동 루프(화면 반짝임) 수정 학습

## 무엇
- 고객센터(`/support`)에서 401 발생 시 자동 로그인 이동 로직이 반복되며 화면이 반짝이는 루프를 수정한다.

### 오늘 작업 대상 파일 경로
- `frontend/src/pages/CustomerCenterPage.jsx`
- `sosos/docs/daily/2026-03-07.md`
- `sosos/docs/work-summary.md`

### 완료 기준(DoD)
- 세션 만료 상태에서 고객센터를 열어도 `/support <-> /auth` 왕복이 반복되지 않고, 한 번만 로그인 페이지로 이동하면 완료.

## 왜
- 기존 로직은 401마다 이동을 재트리거하고, 프론트 사용자 상태가 stale일 때 Auth 페이지가 다시 next 경로로 보내 루프가 발생할 수 있다.

## 언제
- 실제 테스트 중 화면 반짝임 버그가 재현되었으므로 즉시 수정한다.

## 어떻게
1. `401` 전용 핸들러에 `redirectingRef` 가드를 넣어 중복 이동 차단
2. 이동 전에 `refreshSession()` 호출로 프론트 사용자 상태를 서버 세션 기준으로 정리
3. 이후 `navigate('/auth?next=...')`를 `replace`로 1회 이동

## 쉬운 용어 설명
- stale 상태: 화면에는 로그인으로 보이지만 서버 세션은 이미 끊긴 불일치 상태
