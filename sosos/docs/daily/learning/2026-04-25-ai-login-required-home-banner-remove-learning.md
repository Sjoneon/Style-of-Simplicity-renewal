# 2026-04-25 학습 메모 - AI 로그인 필수 + 홈 안내문 제거

## 피드백 반영 (오류/누락 먼저)
- 기존 누락: AI 사용 대상을 `일반 사용자(user)`로만 제한해 `판매자(seller)` 계정이 제외됨
- 수정 방향: `로그인 계정(user/seller)`이면 모두 AI 사용 가능하도록 정책 수정

## 무엇
- AI 스타일 추천 기능을 비로그인 상태에서 사용하지 못하도록 변경
- 로그인 상태라면 사용자/판매자 모두 AI 기능 사용 가능
- 홈 화면 비로그인 안내문(`로그인하면 검색 기록이 저장되고...`) 제거

## 왜
- AI 추천은 로그인 계정 기준으로 사용 이력/선호 데이터 누적이 가능해야 의미가 있음
- 비로그인 접근을 막아야 API 직접 호출 우회 사용을 줄일 수 있음
- 판매자도 상품 맥락 점검/응답 품질 확인 용도로 AI를 사용할 수 있어야 함
- 홈 상단 안내문은 화면 집중도를 떨어뜨려 제거 요청 반영

## 언제
- 현재 리뉴얼 단계에서 사용자 정책을 확정하는 시점
- 배포 전 인증 정책 일관성(프론트/백엔드 동시 적용)이 필요한 시점

## 어떻게
- 백엔드: AI 챗 API에서 세션 로그인 검증 추가
  - 대상 파일: `sosos/src/main/java/com/prosos/sosos/controller/api/v1/AiStylistApiController.java`
  - 정책: `loggedInUser`가 없으면 `401` 반환 (타입 제한 제거로 user/seller 모두 허용)
- 프론트: AI 위젯에서 로그인 상태 분기
  - 대상 파일: `frontend/src/components/AiStylistWidget.jsx`
  - 정책: 비로그인 시 입력/전송 비활성화, 로그인 안내/이동 버튼 표시
  - 정책: 로그인 계정이면 user/seller 구분 없이 사용 허용
- 프론트: 홈 안내문 제거
  - 대상 파일: `frontend/src/pages/HomePage.jsx`
  - 정책: 비로그인 `Alert` 블록 삭제

## 쉬운 용어 설명
- 세션: 로그인 상태를 서버가 기억하는 임시 저장소
- 401: 로그인이 필요하다는 의미의 인증 오류 코드
- 우회 호출: 화면을 거치지 않고 API 주소를 직접 호출하는 방식

## 완료 기준 (DoD)
- 비로그인으로 AI API 호출 시 401 응답
- 비로그인으로 AI 위젯에서 메시지 전송 불가
- 로그인 사용자/판매자 모두 AI 위젯 사용 가능
- 홈 화면에서 기존 로그인 안내문 미노출
