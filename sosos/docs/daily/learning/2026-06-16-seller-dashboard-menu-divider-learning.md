# 판매자 대시보드 좌측 메뉴 구분선 학습 (2026-06-16)

## 무엇
- 판매자 대시보드 좌측 메뉴의 최상위 메뉴 사이에 얇은 실선을 추가한다.
- 드롭다운으로 펼쳐지는 하위 메뉴 안에는 실선을 넣지 않는다.

## 왜
- 메뉴 항목 사이가 시각적으로 나뉘면 운영자가 현재 영역을 더 빠르게 구분할 수 있다.
- 하위 메뉴까지 선을 넣으면 메뉴가 복잡해 보일 수 있어 최상위 영역만 나눈다.

## 언제
- 좌측 메뉴에 여러 운영 영역이 있고, 각 영역의 경계를 더 명확히 보여주고 싶을 때 적용한다.

## 어떻게
1. `SellerDashboardSideNav.jsx`에서 최상위 메뉴 렌더링 사이에 공통 구분선 컴포넌트를 넣는다.
2. `Collapse` 내부의 하위 메뉴에는 구분선을 넣지 않는다.
3. 프론트 린트/빌드와 한글 깨짐 검사를 실행한다.

## 쉬운 용어
- 최상위 메뉴: `운영 요약`, `홈 관리`, `상품 관리`처럼 가장 바깥에 보이는 메뉴다.
- 하위 메뉴: `메인 배너 관리`, `홈 탐색 관리`처럼 큰 메뉴를 눌렀을 때 안쪽에 보이는 메뉴다.
- 구분선: 영역 사이를 나눠 보이게 하는 얇은 선이다.

## 오늘 작업 대상 파일
