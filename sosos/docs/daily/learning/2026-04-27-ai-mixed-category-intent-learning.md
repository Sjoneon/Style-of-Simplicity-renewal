# 2026-04-27 학습 메모 - AI 추천 혼합 카테고리 의도 보강

## 무엇
- 목표:
  - 비의류만 요청(예: 가방만, 신발만)도 정확히 추천한다.
  - 의류+비의류 혼합 요청(예: 상의+가방)도 의도대로 반영한다.
  - 상품 카테고리 값이 부정확할 때(테스트 데이터 오분류) 이름 기반 보정으로 추천 정확도를 높인다.

## 왜
- 이전 보강은 `의류만 요청` 시 비의류 제외에 중점을 뒀다.
- 그런데 실제 요청은 `비의류만`, `의류+비의류 혼합`도 자주 발생한다.
- 테스트 데이터처럼 카테고리(`TOP/BAG`)가 실제 상품명과 불일치하면 의도 필터가 틀릴 수 있다.

## 기존 설명/구현의 누락
- 누락 1: 비의류-only 요청을 고정 검증하는 테스트가 없었다.
- 누락 2: 의류+비의류 혼합 요청(예: 상의+가방)을 고정 검증하는 테스트가 없었다.
- 누락 3: 명시 카테고리 요청 시에도 일반 fallback 점수(기본 패션 추천)로 의도와 무관한 후보가 섞일 여지가 있었다.

## 언제
- 추천 결과가 사용자 요청 카테고리와 다르게 나올 때 즉시 적용한다.
- 배포 전 추천 품질 점검에서 카테고리 일치율을 확인할 때 사용한다.

## 어떻게
- 쉬운 용어 설명:
  - 혼합 의도: 사용자가 서로 다른 종류(예: 상의 + 가방)를 함께 요청하는 것
  - 카테고리 보정: DB 카테고리가 틀린 경우 상품명 단서로 실제 카테고리를 다시 판단하는 것
- 구현 순서:
  1. 요청 문장에서 카테고리 의도를 파싱(의류/비의류 모두)
  2. 상품별 “유효 카테고리”(DB 카테고리 + 이름 기반 보정) 계산
  3. 의도 필터를 유효 카테고리 기준으로 적용
  4. 비의류 전용/혼합 요청 단위 테스트 추가
