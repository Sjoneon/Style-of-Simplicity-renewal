# 2026-03-19 마이페이지 미니멀 디자인 리프레시 학습

## 무엇
- 마이페이지의 기능/데이터 로직은 유지하고, 겉 디자인만 미니멀 리스트형으로 재구성한다.
- 요청 기준: 기능 추가/삭제 없이 UI 톤만 단순하게 정리

### 오늘 작업 대상 파일 경로
- `frontend/src/pages/MyPagePage.jsx`

### 완료 기준(DoD)
- 마이페이지 5개 섹션(주문/혜택/찜·최근본/리뷰·문의/계정)의 기능은 그대로 유지된다.
- 다크 배너 중심 UI를 제거하고, 밝은 배경/얇은 경계선/리스트형 정보 배치로 보인다.

## 왜
- 기존 화면은 카드 강도가 높아 무거운 인상이고, 정보 스캔 속도가 느렸다.
- 사용자 요청처럼 쇼핑앱 스타일의 간결한 마이페이지 톤이 필요했다.

## 언제
- 마이페이지 5개 섹션 기능 정리 이후, 비주얼 톤을 다듬는 단계에서 반영한다.

## 어떻게
1. 데이터 조회/상태 처리 로직은 그대로 유지
2. 섹션 공통 스타일을 흰색 배경 + 얇은 경계선 중심으로 통일
3. 주문/문의 목록을 리스트형 블록으로 정렬
4. 액션 버튼은 텍스트/아웃라인 위주로 단순화
5. 린트/빌드/컴파일로 기능 회귀가 없는지 확인

## 쉬운 용어 설명
- 리프레시: 기능은 그대로 두고 화면의 시각 스타일만 개선하는 작업
