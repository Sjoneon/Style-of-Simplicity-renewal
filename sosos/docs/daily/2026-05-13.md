# 2026-05-13

## 오늘 작업
- 공개 상품 API에서 내부 운영 정보가 과다 노출되던 문제를 점검했다.
- 공개용 `PublicProductDto` / `PublicProductOptionDto`를 추가해 소비자 API 응답을 최소화했다.
- 소비자 화면은 재고 수치 대신 `hasStock`, `soldOut` 신호를 사용하도록 조정했다.
- 공개/관리 응답 경계가 헷갈릴 수 있는 DTO, 컨트롤러, 프론트 재고 판단 지점에 한글 주석을 보강했다.

## 변경 파일
- `sosos/src/main/java/com/prosos/sosos/dto/PublicProductDto.java`
- `sosos/src/main/java/com/prosos/sosos/dto/PublicProductOptionDto.java`

- `frontend/src/pages/ProductDetailPage.jsx`
- `frontend/src/pages/home/homeUtils.js`
- `sosos/src/test/java/com/prosos/sosos/dto/PublicProductDtoTest.java`

## 검증
- `sosos`에서 `./mvnw.cmd -DskipTests compile` 성공
- `sosos`에서 `./mvnw.cmd -Dtest=PublicProductDtoTest test` 성공
- `frontend`에서 `npm run build` 성공
- `scripts/check-korean-garbled.ps1` 실행 결과, 이번 수정 파일은 이상 없었고 기존 `sosos/docs/daily/2026-05-11.md`에서 깨진 한글 패턴 33건이 다시 검출됐다.

## 메모
- 판매자 전용 `/api/v1/products/managed` 응답은 기존 `ProductDto`를 유지했다.
- 공개 응답에서는 `sellerId`, 재고 수치, 옵션별 수량, 키워드, 공개에 불필요한 노출 플래그가 빠지도록 분리했다.
- 주석은 보안 의도와 화면 연동 이유만 짧게 남기고, 동작 설명성 없는 주석은 추가하지 않았다.
