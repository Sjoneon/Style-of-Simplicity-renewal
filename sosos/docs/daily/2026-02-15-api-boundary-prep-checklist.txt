SOS API 경계 정리 전 준비 체크리스트
작성일: 2026-02-15

[목표]
- 경계 정리 시작 전에 실행/환경 기준을 고정한다.
- 이 파일 체크 후에만 Product/Order API 분리 작업에 들어간다.

[A. 서버 실행 명령 (PowerShell)]
1) 프로젝트 이동
cd D:\Projects\Style-of-Simplicity\sosos

2) 빌드
.\mvnw.cmd clean package -DskipTests

3) dev 실행 (기본)
.\mvnw.cmd spring-boot:run "-Dspring-boot.run.profiles=dev"

4) prod 실행 (검증용)
$env:SPRING_PROFILES_ACTIVE="prod"
$env:DB_URL="jdbc:mysql://localhost:3306/SOS_db"
$env:DB_USERNAME="<DB_USERNAME>"
$env:DB_PASSWORD="<DB_PASSWORD>"
.\mvnw.cmd spring-boot:run

5) 헬스체크
- 앱: http://localhost:8085/
- Actuator health: http://localhost:8085/actuator/health
- Actuator info: http://localhost:8085/actuator/info

[B. 내가 따로 해야 하는 준비]
- [ ] MySQL 서버 실행 확인
- [ ] `SOS_db` 스키마 존재 확인

- [ ] 8085 포트 점유 프로세스 없는지 확인
- [ ] 기존 주요 화면 진입 확인 (/, /users/login, /seller/dashboard)
- [ ] 기존 API 호출 확인 (/api/products, /api/orders, /api/inquiries, /api/keywords)
