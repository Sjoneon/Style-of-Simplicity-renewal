# 테스트 계정 네이밍 규칙

## 규칙
- 형식: `{접두어}{순번}.YYYYMMDD@example.com`
- 시작 계정: `a1.YYYYMMDD@example.com`
- 같은 접두어에서는 `1`부터 `9999`까지 증가 (`a1 -> a2 -> ... -> a9999`)
- 순번이 `9999`를 넘으면 접두어를 다음 알파벳으로 변경하고 순번을 `1`로 초기화
- 예시: `a9999` 다음은 `b1`, `b9999` 다음은 `c1`
- 날짜(`YYYYMMDD`)는 계정을 만든 실제 날짜를 사용

## 현재 기준
- 2026-02-19 첫 계정: `a1.20260219@example.com`

## 사용 목적
- API 로그인/세션 검증용 테스트 데이터 식별
- 로그/일지에서 테스트 계정 추적 단순화
