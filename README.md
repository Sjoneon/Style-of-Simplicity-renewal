# SOS 리뉴얼 (Style of Simplicity Renewal)

## 최종 목표
기존 Spring Boot + Thymeleaf 기반 쇼핑몰을 React 프론트 + REST API 구조로 전환하고, AWS 배포 가능한 운영 상태까지 완성한다.

## 지금까지 구현/변경 요약
### 1) React 전환 - 소비자 영역
- 메인 홈, 상품 목록/필터/정렬, 탐색 탭 연동
- 상품 상세 페이지(대표/상세 이미지, 옵션, 재고 표시)
- 장바구니 수량 제어/합계 반영/삭제 흐름
- 고객센터 문의 등록/조회/삭제
  - 문의 카테고리 분류
  - 첨부 이미지 업로드(유효성 제한 포함)
- 마이페이지(MVP)
  - 주문 요약/최근 문의/찜/최근 본 상품
  - 계정 정보/주소/비밀번호 변경
- 알림 페이지(`/notifications`) DB 연동

### 2) React 전환 - 판매자 영역
- 판매자 대시보드 화면/문구 정리
- 상품 등록/수정 UI 개선
  - 모달 기반 등록/수정 플로우
  - 키워드 입력/수정 가능
  - 사이즈별 재고 입력
- 등록 상품 목록 관리(수정/삭제)
- 메인 배너 관리/탐색 탭 관리 분리
- 주문/배송, Q&A 운영 탭 구조 유지

### 3) 결제 영역
- 실제 과금 없는 결제 UI 흐름 구현(모의 결제 흐름)
- 토스 테스트 키 연동 구조 반영
  - 키는 환경변수로만 사용(코드 하드코딩 금지)
  - 서버 확인(Confirm) 구조 분리
- 결제 관련 보안 기본선 반영(비밀키 프론트 금지)

### 4) AI 스타일 추천 영역 (업데이트 중)
- AI 스타일 추천 챗봇 위젯 구현
- 추천 로직 고도화
  - 1차: 키워드/카테고리/계절 기반 필터링
  - 2차: LLM 설명 생성(조건부)
- 다중 턴 의도 해석(카테고리 조합, 계절 변경, 제외 요청)
- 안전 가드레일 반영
  - 유해/혐오/외부몰 유도 문구 차단
  - 무료 티어 한도 고려한 쿨다운/폴백 처리

### 5) 보안/안정성 강화
- 관리자 API 접근 제어 보강
- 백엔드 기동 시 필수 환경변수 Fail-Fast
  - `DB_USERNAME`, `DB_PASSWORD` 누락 시 즉시 실패
  - prod+s3 조합에서 버킷 누락 시 즉시 실패
- 민감정보 분리 원칙 정리
  - `.env.local` 커밋 차단
  - 비밀키/비밀번호 코드 저장 금지
- 문의/업로드 입력값 검증 강화

### 6) 데이터/운영 기능 확장
- 찜(Wishlist) 기능 1차 반영
- 세일/정상가 필드 확장 및 마이그레이션 반영
- 문의 카테고리/첨부 이미지 스키마 반영
- S3 저장 전략 정리(local/prod 분기)

## 현재 진행 상태
### 1순위 (완료)
- 백엔드 운영 기본선 정리 완료
- API 경계 정리 완료
- 주문/재고 무결성 보강 완료

### 2순위 (대부분 완료)
- React 프론트 전환 및 핵심 화면 이관 완료
- 소비자/판매자 핵심 흐름 동작 확인 완료
- AI 추천 및 운영 편의 기능 다수 반영 완료

### 3순위 (진행 중)
- AWS 배포 마무리(EC2/RDS/S3)
- 운영 도메인/CORS 최종 확정
- 통합 회귀 점검 루틴 확정

## 기술 스택
- Backend: Java 21, Spring Boot 3.3.5, Spring Data JPA, MySQL 8.0
- Frontend: React 19, Vite 7, MUI 7, Axios
- Infra: AWS EC2, RDS, S3, Docker
